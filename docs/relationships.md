# 角色关系手账

入口：故事小屋手册书签、角色资料页「关系手账」、一起玩窗口顶部。

先选择自己的角色，再浏览自己的其他角色和已经见过、载入过的房友角色。支持搜索、来源筛选、特别关注；点入查看好感度、阶段、互动次数和最近 30 次共同经历。关系称呼（24 字）、专属昵称（24 字）、手记（500 字）可编辑，按当前角色的视角保存，不改变好友的人设或昵称。

每次双人互动正式开始 +5 点；仅发出邀请、拒绝或开始前取消不计。八种互动共用规则。自己的角色之间共用一条双向成长记录；称呼和备注按视角独立。阶段为初次相识 0、渐渐熟悉 25、相处投契 100、亲密伙伴 300、默契知己 750、长久相伴 1500，之后仍可累积，不自动指定恋爱或家庭关系。

本机 `userData/relationships.json` 原子持久化，串行写入。联机用服务端 session 去重，本地用每次开演 UUID 去重。去重回执不随时间线裁剪。好友角色身份使用服务地址、所属用户 ID 与 manifest.id，换装包 hash 和改名不会重置关系；历史包缺 id 时以缓存目录兜底。遇见的房友在载入时存名片，素材缓存过期后仍保留文字记录，头像无法读取时显示占位。历史缓存可补收录，不追溯既往好感度。

当前是本机养成手账，不做跨设备云同步，不修改服务端，也不把设置发给朋友。联机互动读取已经载入的对方角色；没有角色资料时不能凭用户昵称猜测角色。自己的角色在本地试演也可培养关系，离线房友缓存的模拟互动不计入真实联机关系。

验证：`app/test/relationships.test.ts`、`garden-network-interaction.test.ts`、`pair-interaction.test.ts`、`room-pets-download.test.ts`；`scripts/test-relationships-ui.cjs` 使用真实 Electron、preload、小屋 UI 和实际存档模块，在隔离目录验证列表、详情、保存失败/重试、草稿保护、重读及窄窗口。`QBOT_QA_RELATIONSHIPS_ONLY=1` 运行 `scripts/test-pair-interaction.cjs` 验证实际播放器开始计分、独立 session、开始前取消、联机不重复走本地加分。所有验证均不调用付费模型。
