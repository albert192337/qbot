# 长期记忆与用户画像（2026-09-10 首版）

## 用户入口与调试入口

- 故事小屋顶部「回忆手记」，以及手册书签「我记得的你」。选择角色查看它可见的明确事实、相处偏好、近期事项、共同回忆；待确认观察只在调试页展示。
- 工具抽屉顶部「记忆与用户画像」展示全部角色记录、原文依据、来源角色、时间、共享范围、确定程度、处理队列、更新记录，以及最近 30 次检索的选中/排除原因。修改专属记录时需选中所属角色。
- 用户可纠正、遗忘、结束事项、禁止/恢复主动提及；编辑失败保留草稿。轮询仅在页面可见且没有编辑时进行。显示使用 textContent，来源原文不解释成 HTML。

## 当前实现

数据独立存入 userData/user-memory.json，不进入 characters 资产包，也不发送到联机空间。版本 1、串行事务、同目录临时文件原子替换；损坏文件停止写入并显示错误，不用空记录覆盖原文件。

1. 最近对话按角色保留 40 条/24 小时，重启恢复。助手只在台词实际发送时写入，复用原有 conversation-memory 调用点。
2. 成功的用户聊天结束后，持久化一个整理任务，后台串行请求现有文本模型，每条最多提取 4 项。提取只接收用户本次原话与该角色可见的现有事实，不把助手生成台词当作事实证据。不扫描旧日志回填。
3. 整理任务的 waiting/running/failed 状态落盘；重启后 interrupted running 转 waiting。失败任务由工具抽屉重试。最多 50 个未完成任务，每次调用 15 秒超时，失败不持续自动重试。此过程会产生额外文本模型调用。
4. 每项保存来源原文、来源角色、时间、确定程度、作用域。提取返回的证据必须是用户本次发言的逐字子串，模型输出结构也做校验；这不能替代对模型归纳准确性的真实对话评估。
5. 共享：通用事实、明确偏好、近期事项。隔离：共同经历、对特定角色的约定、秘密。私密语境和 episode 强制角色隔离；私密更新不会覆盖共享副本。当前角色的专属约定在检索和用户视图中优先于同项共享默认值；手动纠正后通过 overrides 关系继续保持覆盖，调试视图仍可查看两份记录。
6. 花园重要收获在保存成功后，写入当次参与角色的共同回忆；普通操作不逐条长期记录。
7. 聊天与自动脑通过 brain-context 共用检索结果，每次最多 12 条。按词语相关度、偏好优先、明确程度与最近更新时间选取；过期、已结束、其他角色私有记录排除。禁止主动提及的记录仅供直接聊天，事项/回忆在提供给主动脑后冷却 6 小时。检索记录表示「提供给模型」，不是「已说出口」。
8. topic 默认 30 天有效，observation 默认 14 天有效；过期记录保留可查，但不送入模型。模型须尊重当前纠正、区分推测，不把其他角色的经历称为自己的经历。

## 纠正、遗忘和失败处理

- UI 纠正/遗忘会失效化在途整理与聊天/主动回复，停止已排队行为。清理脑调用日志和感知行为/决策史，防止其中的旧摘要再次进入上下文。
- 同一来源产生的衍生记忆一起清除；同时清空全部近期对话、检索记录和待整理任务。此首版采取保守的整体清理，UI 提前说明影响。纠正后的条目采用新证据和不含原内容的键。
- 原文不会留在删除历史中，历史只留 ID、操作名、时间。清理日志失败则操作报错、保留卡片供重试。
- 自然语言「忘掉」由后台整理器识别并经同一删除路径处理。复杂或歧义指代的准确性依赖模型；明确操作建议使用手记中的目标卡片。
- 新的用户发言可以形成新记忆；不会从已删除的旧对话自动恢复。

## 尚未包含

- 不根据前台应用自动推断职业、情绪、性格或长期作息。当前观察类来自用户对话，桌面习惯的多日统计与证据阈值留待后续。
- 无向量数据库；首版为有界词语检索。整理器最多读取当前角色可见的最近 80 条事实；很老事项的复杂指代和大规模记忆检索需要后续扩展。
- 无云端跨设备同步、亲密度数值或定时追问任务。主动脑可在正常思考时使用近期事项，但不保证截止日前精确定时提醒。
- 目前按共同来源追踪删除，不跨不同原话进行语义级“同一秘密”全库消除；用户可在调试页检查独立来源的重复记录。
