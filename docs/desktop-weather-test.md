# 桌面天气测试（Windows，2026-09-16）

桌宠右键或托盘「切换天气（测试）」选择流星夜／极光夜。背景约 2.4 秒渐变，前景约 8 秒播完，背景 3 分钟自动恢复；菜单可手动恢复。桌宠菜单首次启动使用桌宠所在屏幕，托盘使用主屏。当前为本地程序绘制的星空、山峦与极光，没有生成照片级素材，也未接自动天气或花园奖励。

## 桌宠反应

天气前景开始后同步触发 8 秒气泡与一次角色动作。流星提醒许愿，极光邀请看天空；优先按动作名称、贴纸标签选择抬头／惊喜／欣赏，再回退到开心、挥手或待机。只选已完成且启用的素材，没有合适素材时只冒泡；不生成新素材、不调用 LLM。显式天气测试在自由模式下也反馈。恢复、切换与换角色时丢弃迟到的反应，隐藏桌宠不主动弹出。

## 白屏修复

旧版把 Chromium 窗口挂入 Explorer，出现无变化或白屏。窗口层级正确和 capturePage 正常都无法证明实际桌面合成成功。现改为隐藏浏览器先生成两张背景 PNG 并验证，再关闭浏览器，由独立原生窗口绘制背景。新版 Windows 11 使用 Progman 下「图标 → 天气 → 系统 WorkerW」顺序；本机 UpdateLayeredWindow 子窗仍不可见，改用 GDI 绘制与 SetLayeredWindowAttributes 后实际桌面显示正常。旧 Electron 挂接代码不再用于产品入口。

- `weather-surface.ts` 准备背景和透明前景，`weather-native.ts` 管理隐藏原生辅助进程，`weather-native-source.ts` 绘制与渐变。新背景淡入时旧背景保持不透明，避免闪白或亮度下陷。
- 前景流星含蓝紫尾迹、发光星头和星屑；极光为上方轻柔光带。前景无底色、鼠标穿透、不抢焦点，8 秒结束并销毁窗口，10 秒硬超时兜底。减少动态效果时不播放前景。
- 背景目前是静态场景，切换有渐变；连续运动集中在短时前景，没有持续视频壁纸。
- 不写系统壁纸、主题或注册表。恢复只关闭天气层，露出当前系统壁纸。退出、锁屏、休眠、屏幕变化和原生层失效会清理；辅助进程监控父进程退出与超时。
- Windows 桌面结构属于 Explorer 实现细节；不支持时清理并提示。macOS 未实现。多屏混合 DPI、虚拟桌面、其他动态壁纸软件兼容性尚未完整测试。

## 验证方法

- 20 项生命周期、菜单与角色反应测试：串行切换、过期创建取消、失败释放、自动到期、续期、手动恢复、锁屏／休眠／屏幕变化和平台限制。
- App 类型检查和构建。
- `scripts/test-weather-bitmap.cjs`：构建后使用 Electron 启动，默认独立小窗预览，`--desktop` 验证实际桌面。独立临时 userData，不改角色／花园存档。
- 脚本使用 desktopCapturer 截取真实合成屏幕，比较原壁纸、渐变中间帧、流星夜、极光夜和恢复后的像素；桌面边缘须露出。另检查前景可见粒子、90% 以上透明像素、不接受焦点以及自动销毁。截图存于 `.superpowers/weather-bitmap/`。测试过程中移动应用会改变截图，中央应用区域不作为壁纸恢复证据。
- `scripts/inspect-weather-desktop.ps1` 只读检查桌面层级。旧 `scripts/test-weather.cjs` 仅为历史挂接实验，不应再用它作为显示成功的验收。
