# 桌面界面优先级

同一角色头顶区域只呈现一种提示。跨窗口不能靠各自 CSS z-index 保证互斥；统一通过 `shared/desktop-overlays.ts` 的表和主进程 `desktop-overlays.ts` 仲裁。

| 优先级 | 内容 | 展示规则 |
| --- | --- | --- |
| 60 | 投喂/已接受互动反馈 | 短时独占，结束后重新读取心愿 |
| 50 | 食物心愿气泡 | 显示时隐藏普通气泡、思考云、开箱提示和任务提示 |
| 30 | 普通/聊天/agent 气泡、思考云、开箱提示 | 没有心愿或互动反馈时展示，隐藏任务提示 |
| 10 | 花园任务提示 | 头顶没有其他提示时展示；任务进度仍保留 |

本表针对头顶提示区域。HUD、用户主动打开的操作面板和侧边留言牌属于独立区域，继续使用各自定位与避让规则；不要把新提示直接塞进这些区域或靠提高置顶等级压过现有内容。

## 生命周期与后续规则

- 高优先级内容通过实际可见性占用区域，低优先级内容隐藏且不拦截鼠标；不是把文字叠在下面遮挡。
- 收起心愿、切角、进入双人动作/种植表演、隐藏桌宠、刷新、崩溃和关窗都要释放相应占用。再显示时重新上报。
- 普通气泡仍走原来的消息期限，过期内容不排队补弹；任务只是隐藏，恢复后显示当前进度。
- 新建窗口先订阅事件并读取带版本号的当前快照，避免先后到达的旧快照覆盖新状态。
- **以后新增桌面提示，必须先确定所属区域，在这张表中明确优先级与互斥关系，并接入共享仲裁；不可只调 z-index。**
- 回归应覆盖不同出现顺序、心愿关闭后恢复、消息在隐藏中到期、新窗晚创建、投喂期间数据刷新、窗口销毁清理和鼠标穿透。

验证入口：`app/test/desktop-overlays.test.ts`、`scripts/test-desktop-overlays.cjs`（实际 preload/气泡/花园 renderer，临时存档、禁网、隐藏窗口）。
