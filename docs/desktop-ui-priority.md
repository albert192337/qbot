## 2026-09-25 最新硬性约束

任何冒泡不得遮挡角色本体或名牌，不依赖素材透明边缘。心愿/互动/房友聊天使用 main/pet-hint.ts 的独立外侧窗，shared/pet-hint.ts 在完整角色矩形之外择位；无空间就不显示。普通气泡同样限制在完整角色矩形之外，内容不得撑过可用区域。隐藏角色时清除提示，不恢复过期内容。此规则覆盖下文历史名牌避让方案。

心愿每角色每天最多两次、间隔至少四小时、每次八秒，手动关闭当天不再展示；renderer localStorage 持久化，不改养成存档。隐身期间不消耗新次数。跨窗口仲裁仍由原角色窗口持有，提示窗只显示文本与响应显式按钮。

# 桌面界面优先级

同一角色头顶区域只呈现一种提示。跨窗口不能靠各自 CSS z-index 保证互斥；统一通过 `shared/desktop-overlays.ts` 的表和主进程 `desktop-overlays.ts` 仲裁。

| 优先级 | 内容 | 展示规则 |
| --- | --- | --- |
| 60 | 双人邀请、投喂/已接受互动反馈 | 自己角色外侧提示窗；邀请接受/拒绝后收起，过期失效，互动期间不叠加新邀请；结束后重新读取心愿 |
| 50 | 食物心愿气泡 | 显示时隐藏普通气泡、思考云、开箱提示和任务提示 |
| 30 | 普通/聊天/agent 气泡、思考云、开箱提示 | 没有心愿或互动反馈时展示，隐藏任务提示 |
| 10 | 花园任务提示 | 头顶没有其他提示时展示；任务进度仍保留 |

本表针对头顶提示区域。HUD、用户主动打开的操作面板和侧边留言牌属于独立区域，继续使用各自定位与避让规则；不要把新提示直接塞进这些区域或靠提高置顶等级压过现有内容。

名字属于独立身份区域，常驻头顶第一行。食物心愿与互动反馈在名牌（含称号）的实际底边下方保留 6px 间距；无名牌时恢复原位置。名牌尺寸变化与房间进出同步更新，不通过遮挡名字解决重叠。

房友窗口有自己的提示区域：聊天使用无杆的说话气泡，放在名牌实际底边下方 6px；聊天显示期间隐藏同步留言牌。离线/素材传输提示优先于聊天，聊天 8 秒后消失，恢复仍有效的同步留言牌。此区域与本机角色提示独立，不抢占本机全局仲裁；同窗互斥由房友 renderer 统一控制，所有提示不拦截鼠标。

## 生命周期与后续规则

- 高优先级内容通过实际可见性占用区域，低优先级内容隐藏且不拦截鼠标；不是把文字叠在下面遮挡。
- 收起心愿、切角、进入双人动作/种植表演、隐藏桌宠、刷新、崩溃和关窗都要释放相应占用。再显示时重新上报。
- 普通气泡仍走原来的消息期限，过期内容不排队补弹；任务只是隐藏，恢复后显示当前进度。
- 新建窗口先订阅事件并读取带版本号的当前快照，避免先后到达的旧快照覆盖新状态。
- **以后新增桌面提示，必须先确定所属区域，在这张表中明确优先级与互斥关系，并接入共享仲裁；不可只调 z-index。**
- 回归应覆盖不同出现顺序、心愿关闭后恢复、消息在隐藏中到期、新窗晚创建、投喂期间数据刷新、窗口销毁清理和鼠标穿透。

验证入口：`app/test/desktop-overlays.test.ts`、`scripts/test-desktop-overlays.cjs`（实际 preload/气泡/花园 renderer，临时存档、禁网、隐藏窗口）。

## 全局隐藏与贴边（2026-09-25）

- 全局隐藏高于所有头顶提示：角色、名字、心愿、互动、聊天、留言牌、花园和天气收起，仅本机 HUD 保留；隐藏内容不得占据鼠标命中区域。
- 贴边窥探只保留本体待机的一部分，名字与全部提示收起；悬停露头区域可展开本机 HUD。
- 房友操作栏是用户操作区域，位于窗口底部；互动选择面板在其上方展开，不参与自动头顶提示优先级。同一时刻只展开一个房友的操作栏。
- 隐藏时释放 wish/interaction/speech，占用恢复按当前状态重新计算；旧气泡及一次性互动不补播。房友说话仍留在房间聊天记录。
- 主进程负责跨窗和晚创建窗口门控，不能用单个 renderer 的 CSS 代替。规则与验证见 [desktop-visibility.md](desktop-visibility.md)。

## 摸摸（2026-09-25）

摸摸用光标和角色本体蹭动，不占提示区域，不新增悬浮文本。发送错误复用有期限的普通气泡与既有仲裁。房间中的摸摸记录不再生成角色聊天气泡；历史记录不重播动作。隐藏、拖动、离场清理小手效果。
