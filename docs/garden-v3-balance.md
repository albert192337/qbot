## 采用的结构

原版附件明确给出的结构：果实 1 / 果皮 1 / 挂饰 2 / 体型 1；天气泊松基础 1.1、参数 clamp 0–5（不限制抽取次数为5）；亲和 0.25、最多4次；十级亲和权重首尾 94:5:1:0 和 72:15:7:6；四档变异肥增量和增重肥区间；杂交双方有槽30%、单方25%、重量独立20%、普通/浓缩容量3/4；每周90次、两类独立十次保底；最多8人、每人360工作量/秒、单人奖励82/8/10；鉴定七行的正负格结构。

附件没有完整配置。中间等级权重、全部物种亲和、因子评分、MassRange、种植时间/种子售价适配、角色XP、合作奖励增幅、操作费用均为本项目配置。天气品质采用附件近似占比归一化，不把取整数字当精确百分比。所有60词条可由 `factorDefinition()` 导出 ID、槽位、评分、来源、亲和、冲突、继承及视觉层。

## 生长、收藏和重量

- 新播种默认 v3；80% 为幼苗期，只在结束时一次结算。记录每段整点天气、毫秒暴露和固定批次随机种子。换房只改变后续批次归属，当前批次不换天气。
- 每小时按 R:SR=140:10 抽取，SSR 自然权重为0；绝对日历每13小时安排一次SSR，包含五种SR、五种SSR，全时段可遇到。测试过60%和80%幼苗档，保留80%让天气预告和施肥有更长反应窗口。
- 同地块同SSR事件最多计一次；前32次天气彩未命中，第33次留一个彩候选。自然天气彩重置，亲和彩不重置。满槽或冲突自动按较高品质优先结算，同品质保持稳定；不再由玩家选择，不重抽。
- 蓝/紫/金/彩普通因子分值4/12/30/60，求和后乘 `kg/标准kg`；体型不加分。整果品质阈值0/25/50/150。颜色喷雾只改变外观。
- 基础重量：94.8% 均匀 [0.45,2.35]；5% 均匀 [3,4.2]；0.2% 均匀 [5,5.6]。体型遗传另用承诺区间。此分布由初轮模拟的长尾问题调整而来。
- 晴日 +[0,0.1]；五种SR约 +[0.05,0.4]；五种SSR约 +[0.3,1]，具体逐天气表在 `V3_WEATHER`。按有效暴露时间加权，之后加肥料、土地和向日葵，最终倍率上限8。迷你<0.6、饱满≥1.5、大型≥3、巨大≥5。
- 新售价＝种子价格/采摘轮数＋24×基础生长小时×(0.7+0.3×封顶6的重量倍率)×min(3,1+普通因子分数和/100)，四舍五入。净种植溢价上限为每基础小时180币，不能把评分直接当售价倍数。
- 十级累计XP为0/20/50/100/170/260/380/540/740/1000。收获XP=`round(4*sqrt(基础分钟/5))`，当天该物种首次+8，每物种每日收获XP最多60。每级新批次时间缩短1%，最多9%；图鉴首发现另奖20XP，联机同时给20花园币，本地继续给原有积分。
- 六组主题收藏和自定义五槽目标，显示最接近的一颗、缺项及具体来源；支持家谱和留养。极限目标不是每日提交要求。

## 合作与角色成长

216000工作量，1/2/4/8人对应600/300/150/75秒。8是活跃培育上限，不要求主人一直在线。无活跃者暂停；连接租期15秒，正常5秒续期，电脑休眠和断开停止。服务重启清租期、保留已做工作。每位≥30秒且≥2%贡献才达标；最终好奖励 `18%+9%*(达标人数-1)/7`，范围18–27%，喷雾/神秘种子保持8:10，每账号每日最多5份物资。

公开消息在原卡更新进度、人数、达标奖励概率和完成参与者，点击定位同一个果实任务；旧任务收获后仍能回看和领奖。世界分享只开放该任务，土地和商店分别授权。拜访不退出当前公共房间，培育使用独立任务场景和8人上限。没有代替用户自动发消息。

每角色独立XP，每天2份稳定补给可获得的草莓/番茄基础10XP＋1份可选词条20XP，免费换一次未完成需求保留原奖励（回到基础草莓/番茄，不让曾经发现稀有水果反过来增加每日负担）。Lv.5后可从已发现、可兼容的词条加入第二项；不要求每日彩色果实。角色升级不提高种植概率/商店额度。基础20XP/日到角色Lv.3/5/8/10需要3/10/31/55天；完成全部40XP/日需要2/5/16/28天；这是食物充足的下界，混合田、1/3/5角色的实际资源竞争见模拟结果。

Lv.3送花、Lv.5相框合影、Lv.8接力（接受者选开心/心心/挥手）、Lv.10庆祝。发起者达等级即可，另一方明确接受；复用兼容动作和物件。投喂用水果靠近消失、开心动作与经验反馈；收藏锁/未揭晓/交易待决果实不可提交。心愿与思考、聊天、培育演出错开，可收起，不欠账。

## 可重复模拟和边界

运行 `npm run simulate:garden`，生成 `output/garden-v3/balance.json` 和 `balance.md`。24个固定随机样本/组；六地块×九物种×频繁（每天8小时、5分钟一次）/每日两次/每日一次；输出7/30/90天余额、每日余额P50、升级时间、首金/首彩/糖心＋鎏金目标的P50/P90。

物种对比为了隔离单位种植效率，假设种子按原价稳定获取，起始资金额外覆盖6包种子，不代表从180币零门槛开满六块稀有田。包含长短作物、60/80%幼苗对比、三肥路线压力情景。路线采用固定随机序列，不可把单条路线结果当统计显著性。多角色模型单独执行真实购买/喷雾/投喂交易，明确起始种子价值、固定每天1次合格合作的资源假设、免费基础种子和补货策略；不拿模拟参与当真实社交数据。

初版低频首彩过长，因此加入5%自然大型体重区间。调整后仍有>90天长尾，收藏目标不得用作每日门槛。长作物在低频查看下保有收益；反复给胡萝卜施高级肥会亏损，肥料是用于特定时间/变异/体型目标的可选消耗，不是自动利润升级。每日免费草莓使误把零钱用于审美购买后仍能继续种植。

商店每周最多21瓶购买；合作每周至多35次物资抽取，喷雾期望单人2.8瓶、8人4.2瓶。多角色共用额度。目标四普通因子全继承＋体型在双方完美同槽且浓缩精油前提下单次约 `0.3^4*0.2=0.162%`，没有算进亲本获取成本，是极限长期收藏而非每日目标。
