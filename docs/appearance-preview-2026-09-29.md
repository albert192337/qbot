# 月蚀：入场、脚印与拖拽残影样板

2026-09-29，按用户要求制作并修订的独立外观试衣间。使用 PixiJS 8.21.0、现有 Spine 播放器与本地透明视频角色，只读素材，不操作正式客户端、角色存档、社交或经济。

## 三类效果

最新修订：花瓣减为每步 3 片，蓝焰改为生成的二维透明图集；黑洞与花瓣已接商城、抽奖与单角色装配，参见[外观物品实现](appearance-items-2026-09-29.md)。下文保留首轮样板的技术背景，以最新实现文档为准。

1. **月蚀之门**：原创程序材质绘制暗核、轻微扰动的银紫边缘与局部月白光带，少量轨道微尘。门展开后角色由远到近显现、轻微虚焦归清，再收起门。一次约 3.2 秒。
2. **步生花**：替换普通鞋印。使用 Spine 张起灵／吴邪的真实 `ship_spine_walk` 动作；按该动作左右脚 Y 关键帧的落地相位（周期起点和半周期）触发，每次从对应 `foot_L`／`foot_R` 骨骼位置扬起七片花瓣，伴少量暖色花粉。花瓣有渐变、折面、翻转和独立飘落，约 3.2～3.9 秒淡去；落点留在场景坐标。移动步幅按角色尺寸匹配现有步态，四个周期后停下。无行走素材的视频角色会切换到 Spine 样例试穿此效果。
3. **苍蓝幽焰**：替换平面人形重影。支持按钮演示和原生鼠标拖动；按移动方向留下蓝焰、细亮火舌和少量蓝色余烬，程序噪声持续向上流动，速度影响火焰大小与漂移。最多 12 片火焰，约 0.72～0.92 秒消散；松手后停止发射。

默认 Spine 张起灵；右上可切换 Spine 吴邪与本地视频张起灵、小青、小白狗（本机素材可用时）；支持深浅背景、重新播放、减少动态效果和窄窗口。视频角色按透明边界测量可见高度，Spine 使用固定相机投影与骨骼脚底坐标。

## 角色边缘与加载修订

- 等待 Pixi VideoSource 完成视频透明模式检测后再显示，避免加载中使用未确定的 alpha 模式；换角色时先撤掉旧贴图，再释放视频／Spine 资源，消除加载交错导致的空资源异常。
- 视频增加局部边缘修整：只在透明轮廓附近压低绿溢色、参考内侧颜色抑制亮边，并去掉极低透明度碎点。角色内部保持原色，Spine 不使用此修整；没有覆盖或重新编码原 WebM。
- 保留视频张起灵中间帧的原始／修整后及浅色背景截图，供检查细节。源视频固有的逐帧画质波动仍可能需要后续从原始绿幕重抠。

## 资源来源

- 渲染库：PixiJS，沿用项目已有依赖与许可。
- 传送门与蓝焰 shader、花瓣、柔光与微光贴图、动作时间线、界面均为本次代码实现；未复制外部 shader，也未引入收费特效素材。

- 角色只读现有本地 WebM 与 Spine 预设，不生成新动作、不修改素材本身。Spine 角色资源沿用仓库现有来源与许可记录，本次不是新增商用授权验收。

## 运行与验证

```powershell
npm run build -w app
node app/node_modules/electron/cli.js scripts/test-appearance-preview.cjs --preview
```

不带 `--preview` 时运行隔离 Electron 验收，截图和结果在 `output/appearance-preview/`。覆盖入场完成、Spine 行走与脚部相位触发、花瓣起点固定、蓝焰拖尾、原生鼠标拖拽、资源过期清理、切模式、减少动态效果、Spine／视频切换、深浅背景、760px 窗口和隐藏暂停；额外保存视频中间帧修整对比。

PixiJS 帧率上限 45，画布分辨率上限 1.5 倍。Spine 复用现有播放器绘制到离屏 canvas，再更新场景贴图；只新增只读 `getSceneFeet()` 接口，不改变正式角色动画逻辑。隐藏时停止场景、视频与 Spine、清掉临时效果；退出销毁渲染器、贴图与播放器。

## 当前范围

这是画布内外观样板，尚未接入正式桌面的入场触发、行走与窗口拖拽。桌面脚印和残影需要独立透明效果层，不能直接让效果跟随整个角色窗口移动。支持现有 Spine 预设和有 idle WebM 的角色；其他骨骼需要自己的落脚相位配置，静态角色尚未适配。

黑洞传送门是首个入场方案，花瓣雨尚未制作。没有商品目录、装备存档、购买或解锁逻辑；是否采用本主题和视觉风格由用户试用后决定。
