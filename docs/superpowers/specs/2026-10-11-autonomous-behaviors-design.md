# 行为属性、主动申请和一天日志

依据：本次用户口述需求；手写照片仅作行为参考。朋友圈默认方式已由用户确认：游戏内自主记录，每角色每天最多三条、至少间隔四小时。真实 API 烟测仍遵循仓库费用约定，本轮用隔离模拟验收。

## 设计

保留现有规则脑、LLM 脑及播放器，增加共享行为政策和主进程授权执行器。相较于每个行为各写弹窗，统一执行器可保证限频、授权、失效与日志一致；相较于重写整个大脑，可复用当前已验收的动作、记忆与社交协议。

LLM 只可选主进程提供的当次机会 ID。机会包含真实目标、角色类型适用性、关系手账、近期互动和当前条件；模型不能创建收件人、坐标或权限。同房且可见的角色才是「旁边有人」；角色库中的角色明确标成邀请本地角色。邀请好友与双人互动逐次请求同意，远端真人继续使用原有对方同意流程。

桌宠外侧复用现有交互提示窗，显示动作、对象、理由、同意/暂时不了。90 秒未答复即取消；隐藏、工作、拖动、离房、换角或相关资料变化时失效。每次同意仅对应一个请求 ID；重复点击不重复发送。拒绝也占提示次数，避免催促。

朋友圈使用真实当日记录，有新经历才触发；生成请求在调用前持久预占次数，失败不立即重试。游戏内本地卡片与联机花园资产分开，在线切换不得丢卡片或绕过次数。

双人互动复用完成动作，表情包/视频/Spine 均按素材回退。打闹只抛桌面图标图片副本，不读取文件正文，不修改图标或原文件；缺少图标时用通用纸团道具。无抓握动画的角色使用悬浮抛物线与表情反馈。播放设有限总时长，退出、失败与切换完整释放访客、朝向和占用。

行为表保留每项真实完成状态，区分「可做」「可自主提议」「需授权」「素材回退」「尚未实现」。不会把角色视频重生成当作即时行为能力，也不会把菜单入口当作主动触发已接通。

## 验收

共享策略与真正运行的授权执行器模拟 24 小时，覆盖同意、拒绝、无回复、换角、离房、重启、失败、日界、限频与重复点击。日志区分申请、批准、开始、邀请送达、完成、拒绝、过期、取消、失败。普通动作也写角色和来源。隔离 Electron 检查提示窗与双人播放自然结束，普通测试禁止付费 API 和真实好友消息。
