# 双人气泡与测试面板避让

按用户截图修复：双人气泡不能遮挡任一角色，转向/换边/结束测试面板位于气泡和角色上方。此前双人气泡按画布百分比摆放，与完整角色矩形相交，未遵循普通气泡的避让规则。

双人画布增加240 DIP头部空间，保留原角色绘制区域大小；进入时优先向上扩展，工作区不足时整体钳制并缩小角色区域。台词底边距两个角色矩形顶边8 DIP，按说话者对齐并限制在窗口内；测试面板位于实际台词顶边上方8 DIP。长台词、换边、窗口缩放触发重新测量。极矮工作区头部最多占60%，普通单人尺寸和退出恢复保持原逻辑。

特效继续锚定角色区域，避免扩大窗口后抛掷和茶桌错位。复用现有窗口和导演，不新增独立浮窗。验证真实Electron长台词、双人角色矩形与面板互不重叠、最小缩放、窄工作区、换边、按钮操作及退出恢复；不调用付费模型或真人邀请。
