# 正式桌边花园：3D 草地 + 2D 植物

用户已通过三方向小样选定第二方案，并要求保留旧版切换。继承上一轮图标优先、单击摇晃、双击收获的交互。

## 范围

- 增加 `hybrid` 显示偏好；原有 2D 和 3D 渲染及切换保留。共用正式 GardenState、播种、收获、培育和库存接口，无存档迁移及服务端规则变更。
- 草坪沿桌面工作区底边连续铺开，使用圆润、简化的 3D 地形。按实际已解锁地块显示植物和空种植点，不增加虚构地块。植物使用正式种类对应的二维美术，覆盖幼苗、生长、成熟和待揭晓阶段；待揭晓不暴露实际变异。成熟变异体现颜色、大小、双生、光点；保留染色。
- 新版支持全部正式植物。原版 3D 的草莓／菠萝限制保持原样。
- 单击植物摇晃；双击成熟、可收获且未保留的本人成熟植物调用正式收获。空位单击打开该地块播种，未成熟／待培育植物双击打开详情。不代收他人作物，不越过现有揭晓和保留规则。
- 新版原生画布在 Explorer 图标下、壁纸上。离屏 Electron 不显示；工具栏独立保留在原 strip，仅工具栏可捕获点击。鼠标旁听只接收桌面空白范围，图标、应用窗口及拖拽优先；不吞原鼠标事件。
- 收起花园、隐藏角色、全局隐藏、锁屏、休眠、退出、切回旧版均清理原生画布和离屏渲染；恢复时只在花园原本展开且角色可见时恢复。异步启动过期不得再出现。显示器变化重新定位；失败保留切回原版入口。

## 实现顺序

1. 拆出共享的安全显示描述与桌面点击决策，覆盖全部阶段、保留、重复点击和访客限制。
2. 新增混合场景及独立透明渲染页；复用小样原生宿主，补充正式生命周期。
3. 正式花园窗口接偏好通知、工具栏切换和投影坐标；原版代码路径保持。
4. 类型检查、规则测试、正式页面隔离 Electron 验证：种植／收获、模式切换不改资产、显示及资源清理、原生层级和失败恢复；构建后更新本机实例。

## 验证边界

测试使用隔离存档及受控作物，不操作真实用户资产。原生坐标桥接注入与真实鼠标／Explorer 合成验收区分记录。画布 18fps 上限、帧传送背压，减少动态时静止；不宣称长期功耗或所有 Windows 版本兼容。
