# 花园生活实现计划

用户已批准 `docs/garden-next-development-todo-2026-09-22.md` 并要求开始开发。

1. 复用花园纯规则与串行存档，增加日商店、喷雾、角色心愿和成长配置，保持旧资产兼容。
2. 实现目标校验、消费与结果原子结算；补充日切、重试、满槽、错材料和角色隔离测试。
3. 花园界面加入喷雾、每日货架、心愿提交、成长解锁；桌宠加入可点击食物气泡。
4. 房间服务使用构建时生成的独立规则包（部署目录不跨仓库 import），按真实账号存档；本地旧花园保留，联机模式显式开启。
5. 统一好友/成员的土地、商店入口，服务端校验权限、跨店额度与幂等交易；接通合作培育与互动邀请。
6. 丰富词条和效果，将新版槽位、概率、品质规则明确版本化；真实 UI 与隔离双客户端验证。
7. 跑相关测试、类型检查、构建和独立服务集成，记录已交付范围与未部署边界。

实现中使用当前仓库指南及已读 brainstorming 流程。此环境没有可调用的 writing-plans 技能文件，实施步骤在本文件直接记录；不重复请求已获得的设计批准。

## 本轮验收

1–5 以及 7 已完成；6 的词条定义、喷雾来源/槽位、复用效果及 UI 验证完成，植物整体数值 v3 尚未切换。详细入口、参数出处、测试证据及尚未开发的长期范围见 `docs/garden-life-development.md`。未部署现网。
