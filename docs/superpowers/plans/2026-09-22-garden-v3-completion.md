# 花园 TODO 完成计划

用户已明确要求按既有 TODO 开发完，并强调好玩。沿用已批准设计，不再次设置审批门槛。原版缺失配置使用有来源标记的项目起测表，不假称原版精确值。

顺序：① v3 有限槽位、综合品质、十级物种与阶段结算；② 四档肥料、重量、遗传/保底和鉴定；③ 收藏目标/谱系/反馈、统一名片和权限、共同记录/动态邀请；④ 太阳花互助和主题内容；⑤ 六地块九物种、多作息多角色的可重复经济模拟；⑥ 端到端验证、迁移验证及逐条核验 TODO。

玩法约束：玩家自选目标，未上线无惩罚；基本种植与培育可独立完成；稀有抽取有明确来源和可解释保底；满槽结果供选择，不能悄悄覆盖收藏；短作物用于随手反馈，长作物承接离线；不为增加每日活跃堆任务。

数值适配决策：幼苗先用 80%（模拟另测 60%）；肥料按每轮而非整株；旧八级 XP 在开通 v3 时保持同级和级内进度；新植物最高十级。日常经验有每物种每日 60 上限及首次收获加成，降低高频点击优势；不封顶出售。新售价以时间收益加种子摊销定价，重量/词条溢价有总上界。鉴定为可随时收手、失败不毁果的有限冒险，单果一次，不收费复活。

Nintendo 参考：[作息适配](https://iwataasks.nintendo.com/interviews/3ds/animalcrossing-newleaf/0/1/)、[个人表达与拜访](https://iwataasks.nintendo.com/interviews/3ds/animalcrossing-newleaf/0/3/)、[单人及交流](https://iwataasks.nintendo.com/interviews/3ds/animalcrossing-newleaf/0/5/)。以上落地机制为本项目判断，不是任天堂提供的数值。是否好玩最终还需要真人试玩；本轮交付自动验收路径及本地体验日志供检验。
