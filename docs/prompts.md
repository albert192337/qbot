# 生成管线 Prompt 一览

本文档梳理 QBot 生成管线用到的全部 prompt，源码位于 `pipeline/src/prompts.ts`（模板文本逐字取自 DESIGN.md §3.3，实测有效，不要随意改写措辞）。

整体结构是 **3 个模板 × 2 种角色形态 × 6 个动作**（人形档三视图另有 2 种生成风格）：

- 三个模板：三视图（`turnaroundPrompt`）→ 视频首帧（`framePrompt`）→ 循环视频（`videoPrompt`），分别在 `pipeline/src/stages.ts` 的三个阶段调用。
- 两种形态（`CharacterForm`）：`humanoid` 人形档、`abstract` 抽象档（线条小狗、简笔涂鸦、几何形等非人形角色）。
- 两种风格（`CharacterStyle`，仅人形档）：`chibi` 二头身 Q 版（新建默认）、`faithful` 高保真。影响三视图、首帧、视频三处措辞：faithful 去掉首帧的贴纸风尾巴（否则被拉回卡通风）、动作文案连耳朵也不提（写实角色任何部位命令都可能凭空长出该部位）、并显式排除接触阴影（写实渲染爱画阴影，阴影是暗绿色抠像处理不掉）。「尾巴」二字则全档禁用，见经验第 6 条。
- 六个动作（`ActionId`）：`idle`、`drag`、`sleep`、`tea`、`talk_happy`、`talk_annoyed`。

## 一、三视图 prompt（`turnaroundPrompt`）

图生图，参考图 = 用户上传的原图。

**人形档 · Q 版（`chibi`，UI/CLI 新建时的默认）：**

> 角色三视图设定表：把参考图中的角色重新设计为二头身Q版chibi风格：大头圆脸小身体，圆润可爱，保留参考图中角色的发型、发色、眼睛颜色、耳朵等标志性特征和服装的主要配色与元素，使其可以被一眼认出是同一个角色。画面从左到右水平排列三个完整站立全身视角：正面、正侧面、正背面，三个视角的角色比例、发型、服装细节完全一致，双臂自然下垂，表情为自然平静的默认表情。可爱贴纸插画风格，纯白色背景，无阴影，无文字，无水印

设计动机：用户输入可能是任意素材（照片、复杂插画、非贴纸风角色），Q 版重绘对任意输入都稳定，且桌宠场景贴纸感更强。

**人形档 · 高保真（`faithful`，函数缺省值——旧 job resume 时沿用旧行为）：**

> 角色三视图设定表：参考图中的角色，保持参考图中角色的发型、眼睛、神态、耳朵等特征、服装、头身比、画风完全一致。画面从左到右水平排列三个完整站立全身视角：正面、正侧面、正背面，三个视角的角色比例、发型、服装细节完全一致，双臂自然下垂，表情为自然平静的默认表情。纯白色背景，无阴影，无文字，无水印

其中「保持参考图中角色的发型……完全一致」和「自然平静的默认表情」是 `CharacterDesc` 的两个槽位（`summary` / `defaultExpression`），MVP 阶段用固定默认值 `DEFAULT_CHARACTER_DESC` 填充；还原度不够时的后续方案是接 VLM 自动提取角色描述（spec §8 风险项）。注意 chibi 档不使用 `summary` 槽位（重绘语义与逐字保持冲突），只保留 `defaultExpression`。

**抽象档**（无头身比概念，忽略风格选项）：

> 角色三视图设定表：参考图中的角色，完全保持参考图中角色的形态、线条风格、颜色、比例与画风。不要拟人化，不要添加参考图中没有的四肢、五官、服装或任何部位。画面从左到右水平排列三个完整全身视角：正面、正侧面、正背面，三个视角的角色细节完全一致。纯白色背景，无阴影，无文字，无水印

## 二、视频首帧 prompt（`framePrompt`）

绿幕首帧，图生图，参考图 = 选定的三视图。

结构 = **保持一致性开头 + 动作姿势描述（`poseDesc`）+ 固定尾部**。

**保持一致性开头：**

- 人形档（chibi / 缺省）：`参考图中的角色，保持发型、眼睛、服装、耳朵等所有细节完全一致。`
- 人形档（faithful 高保真）：`参考图中的角色，保持发型、眼睛、服装、画风、头身比等所有细节完全一致。`（连耳朵也不提，防止给人类角色长出来）
- 抽象档：`参考图中的角色，完全保持其形态、线条、颜色、画风等所有细节一致，不要添加参考图中没有的部位。`

**固定尾部（chibi / 缺省 / 抽象档）：**

> 画面中只有这一个角色，没有其他人物、没有手、没有家具、没有白色贴纸描边。背景为纯色绿幕（纯正绿色，无渐变无阴影无纹理），角色边缘描线清晰，全身完整可见，角色占画面高度约70%，粗描边贴纸插画风格，无文字无水印

**固定尾部（人形档 faithful 高保真）**——把「粗描边贴纸插画风格」换成保持参考图画风，「描线清晰」换成「清晰锐利」（描线是线稿词汇，会往插画风引导），并在排除句后追加阴影排除：

> 画面中只有这一个角色，没有其他人物、没有手、没有家具、没有白色贴纸描边。角色不投射任何阴影，地面和背景上没有任何阴影。背景为纯色绿幕（纯正绿色，无渐变无阴影无纹理），角色边缘清晰锐利，全身完整可见，角色占画面高度约70%，完全保持参考图的画风与头身比不变，无文字无水印

经验教训：贴纸风尾巴的正面引导（「粗描边贴纸插画风格」）足以在首帧阶段把高保真三视图重新拉回卡通插画风，甚至引出 prompt 明确排除的白色贴纸描边——正面风格描述的权重高于排除句。

**人形档 poseDesc：**

| 动作 | 姿势描述 |
|---|---|
| idle | 角色自然站立，双臂自然下垂，表情平静放松。没有手、没有其他任何人物或物体。 |
| drag | 角色悬浮在半空中，身体微微前倾，双腿自然下垂放松，表情略带惊讶。没有手、没有绳索、没有其他任何人物或物体，角色周围完全空无一物。 |
| sleep | 角色蜷缩侧躺姿势闭眼熟睡，表情安详。画面中绝对没有床、没有枕头、没有被子，只有角色悬浮在纯绿背景上。没有手、没有其他任何人物或物体。 |
| tea | 角色坐姿，自己的双手捧着一只小茶杯放在胸前，表情惬意满足。画面中只有角色和茶杯，没有桌子、没有椅子、没有其他任何人物或物体。 |
| talk_happy | 角色四分之三侧身朝向画面右侧，表情开心，眼睛明亮，嘴巴微张像在愉快说话。没有手、没有其他任何人物或物体。 |
| talk_annoyed | 角色四分之三侧身朝向画面右侧，表情不耐烦，眉头微皱，嘴角向下撇。没有手、没有其他任何人物或物体。 |

**抽象档 poseDesc**（铁律：绝不提及双臂/双腿/坐姿/发型/服装/耳尾等部位假设——模型会顺着描述凭空长出这些部位，一律用「整体」「姿态」「轮廓」级别的措辞）：

| 动作 | 姿势描述 |
|---|---|
| idle | 角色保持参考图中原本的自然姿态，安静放松。没有其他任何人物或物体。 |
| drag | 角色悬浮在半空中，整体微微倾斜，显得轻盈。没有绳索、没有其他任何人物或物体，角色周围完全空无一物。 |
| sleep | 角色蜷缩成一团安睡，姿态安详。画面中绝对没有床、没有枕头、没有被子，只有角色悬浮在纯绿背景上。没有其他任何人物或物体。 |
| tea | 角色身前放着一只小茶杯，角色凑向茶杯，姿态惬意。画面中只有角色和茶杯，没有桌子、没有椅子、没有其他任何人物或物体。 |
| talk_happy | 角色朝向画面右侧，整体姿态欢快，像在愉快地表达。没有其他任何人物或物体。 |
| talk_annoyed | 角色朝向画面右侧，整体姿态显得不耐烦。没有其他任何人物或物体。 |

## 三、循环视频 prompt（`videoPrompt`）

i2v，首帧 = 尾帧，走 Ark 1.0 系列的 prompt 尾部参数约定。

结构 = **动作运动描述（`motionDesc`）+ 固定尾部 + 参数尾巴**。

**固定尾部（chibi / 缺省 / 抽象档）：**

> 镜头完全固定不动，静止镜头，角色不位移不走出画面，绿幕背景纯绿色保持不变，画面中始终只有这一个角色，绝对不出现其他人物、手或物体。丝滑流畅循环动画。

**固定尾部（人形档 faithful 高保真）**——追加阴影排除：

> 镜头完全固定不动，静止镜头，角色不位移不走出画面，绿幕背景纯绿色保持不变，角色不投射任何阴影，画面中没有任何阴影，画面中始终只有这一个角色，绝对不出现其他人物、手或物体。丝滑流畅循环动画。

**参数尾巴：**

```
 --resolution 480p --duration 5 --camerafixed true
```

所有动作 `durationSec` 均为 5——seedance 1.5-pro 最短 5 秒，传 3 会返回 400。

**人形档 motionDesc（chibi / 缺省）：**

| 动作 | 运动描述 |
|---|---|
| idle | 角色站立原地，身体随呼吸轻微起伏，偶尔眨眼，耳朵轻微自然摆动。动作幅度很小。 |
| drag | 角色悬浮在半空，身体轻微摇晃，双腿自然晃动，表情略带惊讶地眨眼。角色不位移。 |
| sleep | 角色闭眼熟睡，身体随呼吸缓慢起伏，耳朵偶尔轻颤。动作幅度很小，安静祥和。 |
| tea | 角色捧着茶杯小口喝茶，喝完满足地眯眼微笑。角色不位移。 |
| talk_happy | 角色朝画面右侧开心地说话，嘴巴一张一合，表情生动，偶尔点头，耳朵竖起。角色不位移。 |
| talk_annoyed | 角色朝画面右侧不耐烦地抱怨，嘴巴撇着动，偶尔翻白眼或扭头，耳朵向后压。角色不位移。 |

**人形档 motionDesc（faithful 高保真，`FAITHFUL_ACTIONS`）**——姿势与上表相同，运动描述连耳朵也不提（写实角色任何部位命令都可能凭空长出该部位），换成头发级别的自然运动：

| 动作 | 运动描述 |
|---|---|
| idle | 角色站立原地，身体随呼吸轻微起伏，偶尔眨眼，头发轻微自然飘动。动作幅度很小。 |
| drag | 角色悬浮在半空，身体轻微摇晃，双腿自然晃动，头发轻轻飘动，表情略带惊讶地眨眼。角色不位移。 |
| sleep | 角色闭眼熟睡，身体随呼吸缓慢起伏。动作幅度很小，安静祥和。 |
| tea | 角色捧着茶杯小口喝茶，喝完满足地眯眼微笑。角色不位移。 |
| talk_happy | 角色朝画面右侧开心地说话，嘴巴一张一合，表情生动，偶尔点头，头发随动作轻轻晃动。角色不位移。 |
| talk_annoyed | 角色朝画面右侧不耐烦地抱怨，嘴巴撇着动，偶尔翻白眼或扭头。角色不位移。 |

**抽象档 motionDesc：**

| 动作 | 运动描述 |
|---|---|
| idle | 角色停在原地，整体随呼吸轻微起伏，轮廓微微颤动，偶尔小幅晃动。动作幅度很小。 |
| drag | 角色悬浮在半空，整体轻轻摇晃摆动，像被微风吹动。角色不位移。 |
| sleep | 角色安睡，整体随呼吸缓慢起伏。动作幅度很小，安静祥和。 |
| tea | 角色凑近茶杯小口喝茶，随后满足地轻轻晃动。角色不位移。 |
| talk_happy | 角色朝画面右侧欢快地表达，整体节奏轻快地晃动点动，姿态生动。角色不位移。 |
| talk_annoyed | 角色朝画面右侧不耐烦地表达，整体急促地小幅晃动扭动，偶尔别开。角色不位移。 |

## 贯穿的 Prompt 设计经验（防翻车规则）

来自 DESIGN.md §3.3 与代码注释的实测经验：

1. **不引出手**：不描述「被拎住」之类会引出手的措辞，只描述姿势本身；所有 prompt 都显式排除「没有手、没有其他任何人物或物体」。
2. **sleep 排除床品**：显式排除床/枕头/被子——床是客户端垫的资产图层，不能让模型画出来。
3. **抽象档不提部位**：绝不提及双臂/双腿/坐姿/发型/服装/耳尾等部位假设，否则模型会凭空长出这些部位。
4. **视频可循环可抠像**：强调「镜头固定、角色不位移、绿幕纯绿不变」，保证首尾帧衔接循环与后期抠像。
5. **正面风格描述权重高于排除句**：写了「没有白色贴纸描边」，但只要有「贴纸插画风格」四个字描边照样出现——faithful 档必须整句删掉贴纸风尾巴，而不是靠排除句对冲。
6. **全档禁提尾巴**：不管角色本身有没有尾巴，命令式的「尾巴摆动」都会让模型凭空长出一条（写实喝茶动作实测长出猫尾巴）——所有形态/风格的 prompt 一律不出现「尾巴」二字；faithful 档连耳朵也不提。
7. **faithful 排除阴影**：写实渲染爱画接触阴影，阴影是暗绿色，抠像永远处理不掉，必须在生成端排除。
