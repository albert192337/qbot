## 原因与修复

1. `run()` 在确认前后重建整张页面，生成方式、秒数、描述未纳入状态；看起来像按钮无效，也会丢失重试内容。改为按角色与源资源保留页面内生成草稿。
2. 校验、提交错误只写页面顶部，底部按钮附近看不到。改为就地显示校验/提交/失败/完成状态，保留输入。
3. 新版本进度事件只改顶端一句文字，不更新预览列表。改为只刷新新版本区域，保留其他输入、候选和人工编辑。
4. 任务列表只展示待处理任务，成功后移出是当前设计。说明完成结果保存于角色库；成功提交后提供直接查看任务/新版本入口，进行中禁用同一表单重复提交。

本次未加入自定义动作的视频任务持久化恢复，也没有把历史付费请求重新提交。生成后仍须显式将新版本加入待机或其他场景。
