- 目标图：鸣人目标图只作风格与比例参考，文字指定少年佐助；复用 Seedream 实验的目标提示词，CLI 报告 33.9 秒。
- 部件图：参考新 GPT 目标图，明确九部件、完整双臂、独立单腿和无袖躯干，CLI 报告 36.0 秒。部件提示词针对上一轮错误作了加强，因此不是严格控制变量的模型评测。

- 输出 `output/spine-lab/sasuke-gpt/target-v1.png`、`parts-v1.png`；最终提示词 `target-prompt.txt`、`parts-prompt.txt`，时间记录 `*-result.json`、`*-cli.log`。目标经助手检查后用于用户要求的比较实验，尚未获得用户对新目标的独立定稿确认。

## 实际质量与处理

这张部件图含完整的九个独立对象，头发／衣服与目标基本一致，双臂都有完整上袖，两腿各自独立；无需跨版本选件，也没有镜像补另一臂。目标图的袖子向下垂，比 Seedream 试验中的平直袖帽更贴近要求。仅凭一个样例不能推断稳定成功率。

图像为品红背景，使用附带 `remove_chroma_key.py` 做本地透明提取，并非 API 原生透明输出。之后 `prepare-sasuke-gpt-trial.py` 检测连通部件，按三行位置排序、留空隙打包；检测不足九件直接失败。人工检查部件语义，程序只验证数量和分离性。

最初复用旧模板位置会把手臂压短、压宽，上衣遮住短裤。调整独立校准文件后，袖子变窄、手臂加长、远侧手臂外移，上衣下摆缩短。眼位沿用模板初始化后人工检查，仍非自动锚点识别。身体相对目标图仍偏紧凑，短袖与肩部仍需用户视觉评估，不能把模型生成质量与装配质量混为一谈。

复现顺序：去底 → `python scripts/prepare-sasuke-gpt-trial.py` → `python scripts/spine-lab-hood.py output/spine-lab/sasuke-gpt-parts.png sasuke-gpt` → `node scripts/calibrate-naruto-mesh.cjs sasuke-gpt` → `node scripts/calibrate-spine-sleeves.cjs sasuke-gpt`。后两步需要本地实验服务器与 Playwright/Electron。重新打包后必须重做网格校准。

## 肩部返修 v2

用户仍否定肩部连接。局部放大确认两种问题：袖根偏离骨骼装配位置；躯干原图两侧自带肤色袖窿。单纯移动手臂无法消除画在躯干上的肤色缝。

- 同一 GPT 兼容接口追加一次躯干部件编辑，23.4 秒，提示词 `torso-repair-prompt.txt`，输出 `torso-repaired.png`，去底结果 `sasuke-gpt-torso.png` 由打包器自动采用。该素材问题由助手判断和触发，未实现自动语义质检。累计三张生成图、CLI 报告等待合计 93.3 秒，实扣未知。
- `scripts/auto-spine-shoulders.cjs sasuke-gpt` 从模板重建袖网格，读取图集 alpha 检测袖帽顶部 10%–23% 的实体质心，在已审阅的模板盒范围内求袖根；沿肩关节与袖宽推导横向搭接，保持已审阅的肩线高度。超出修正边界／根部像素不足则报错，不自动生图。
- 修正衰减到前臂，手部几何位置保持不变；袖根增加胸部／上臂过渡权重，下段保留上臂／前臂绑定。初次直接匹配骨骼高度会把袖帽抬至下巴，该候选被视觉检查拒绝；算法现在只修横向，不宣称自动判断肩高。
- 使用全新 setup skeleton，排除正在播放的动作／变形污染；连续运行两次 JSON SHA256 一致，手部最大位移为 0。此算法只开放已审阅的两个佐助实验 profile，本次仅 GPT 版做了视觉验收；不能声称任意人形通用。
- 打包或普通袖网格重建后，最后必须执行自动肩部脚本。验证结果 `sasuke-gpt-shoulders-v2/`，预览 `?skin=sasuke-gpt&expressions=1&v=2`。短袖接缝轮廓仍需用户最终审阅。

## 用户否定 v2 后的分层修订 v3

v2 不能视为视觉通过。用户截图仍显示袖帽像肩甲、手臂向身体内收。仅去除肤色裂缝与保持手部原位不足以满足要求。

v3 在 GPT 佐助 profile 中重新求自然站姿手部横向位置，近侧手外移约 20.15 骨架单位、远侧约 3.92，保留手部高度，平滑影响前臂。此项替代 v2 的“手部不得移动”假设；不是通用手部姿态识别。

新增 `layer-spine-sleeve-caps.cjs sasuke-gpt`：近侧袖帽三角形单独放到躯干后方，前臂／手保留前景，使袖帽内边不再像贴片盖在胸前。按原动作完整解码并重编码绘制顺序，插入层随躯干保持遮挡关系；实验播放器保留新袖帽层。并非单纯把整条手臂放到身后。

复现顺序更新为：打包 → 躯干校准 → 自动肩部脚本 → 袖帽分层脚本。对已分层资产直接再次校准会拒绝，须先重新打包，防止残留旧袖帽。没有追加生图。输出 `sasuke-gpt-arms-v3/`，预览 `?skin=sasuke-gpt&expressions=1&v=3`。技术检查不能代替用户视觉认可，本版仍是候选。

## 隐藏颈部的轮廓实验 v4

用户指出 v3 仍耸肩，可能源于角色规范对脖子的假设。创建主规范已取消可见短颈的默认要求，优先隐藏颈部／低薄领边／自然下落肩线，仍保留全部头颈骨控制。

`apply-spine-hidden-neck.cjs` 在自动肩部之后、袖帽分层之前运行：基于 UV 的衣领局部压缩最大 10 世界单位，躯干侧肩和袖帽下放最大 8 单位，向腰／腕衰减；头骨从原模板缩短 10 单位（v3 为 4），五官随头一起变化。对每个骨骼影响分别做世界／局部坐标转换，保留权重和动作。这些参数由人工选定，不是机器自动识别的衣领锚点。
