## 1. 为什么“喜欢收藏”会导致现金不足

以无词条、标准重量莲花为例：种子65，售价89。若每批35%留藏，其余65%出售，则每批平均销售回款为57.85，低于种子成本65，尚未计算送礼。即使金币消费停止，这种策略仍可能逐渐缩小种植规模。

维持同样种植规模的最低出售比例为65/89≈73.0%。自然词条和重量会改变实际门槛，因此这个算式解释方向，不替代报告中的随机生长结果。

### 下一轮先验证行为假设，再改经济

1. **唯一收藏策略**：首次见到的物种/词条组合保留；重复款出售。记录收藏率是否随时间下降。当前恒定35%为压力情景，不能据此认定真实用户都会破产。
2. **周转提醒策略**：可用现金低于下一轮所需补种成本时，提示种较便宜的作物或出售未锁定重复物。只提供建议，不自动卖藏品。
3. 上述两项仍失败，再比较“收藏里程碑一次性种子补给”。补给按物种/组合首次去重，并将未来产出全部入账。不要先普遍提高售价，否则会加重常驻通胀。

二次通过目标：重收藏策略Day7至少能安排第一次正常地区旅行；Day30付费家具P50≥5；至少90%样本有能力补种下一轮，而不是只凭每日免费草莓维持。

## 2. 常驻玩家需要后续内容预算

基准Day60也有约10,998现金，说明首批12件目录是一个阶段的容量。不能把停止消费后的余额增长误判成售价公式有bug，也不能以新增无穷升级消耗掩盖内容成本。

下一轮分别比较：

- 原有喷雾、繁育、土地等真实自选开销，对现金结余能吸收多少；不得把玩家一定会花这些钱当既定事实。
- Day30追加6件可预览的主题家具，候选总价8,000/12,000/16,000三档。此处只是后续敏感性输入，未加入当前报告、未宣称调平。
- 将固定“每天最多买一件”的模拟策略去掉，允许一次买完可负担目录，观察内容更早耗尽的时间。

通过目标：常驻玩家可明显更早完成主题，但下一期首日不能直接买完所有新内容；同时基准玩家不因追新而被迫放弃旅行。以内容完成时间和种植周转能力判断，不强求所有玩家持有相同金币。

## 3. 短时用户需要一条完整的小回路

目前30分钟教学旅行，加上播种、收获和购买操作，无法在30分钟首场内完成。这个结果符合计时逻辑，不是后台出错。

待比较的两个版本：

|候选|修改|如何验证|
|---|---|---|
|A，优先测试|教学旅行改为10分钟；费用和奖励不变，普通旅行保持原时长|首次30分钟场次内至少80%人完成取回和陈列|
|B|保留30分钟；首场先给出发合照，归来奖励次日领取|确认用户能理解“已得到纪念”与“旅行尚未完成”|

A优先，因为无需增加半完成状态和额外资产。改变前仍保留本次30分钟结果，不能把旧结果当作10分钟新配置的模拟。

## 4. 低频关系要有早期反馈

30分钟每天的共处1分＋主动互动1分，18天才达到熟悉。可先在累计10分给一次明确的早期回应事件，保留35/180/400阶段门槛。这样第5天出现变化，又不会把长期关系加速十倍。

这个候选事件只改变反馈，不额外发金币或关系分：例如首次主动招呼、引用初见记忆。三类角色都需验证可见性。基准固定同伴用户约第2天即可看到，也必须保持合理，不必称为亲密。
