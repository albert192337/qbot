# 桌边花园：三方向交互小样

2026-10-11。用户认可简化草坪的概念图，要求同时尝试纯 2D、3D 草地搭配 2D 植物、纯 3D，并希望精细模型不足时提供图片交给 Tripo。

## 打开与操作

- 双击仓库根目录 `打开花园小样.cmd`，或执行 `node scripts/preview-garden-styles.cjs`。
- 默认显示混合版后期花园。顶部切换三个方向、新手／后期、微风和变异；单击植物轻摆，双击成熟植物模拟收获并变回幼苗，点击小兔跳跃。收获不改变正式库存；切换阶段或“看它长大”恢复植物。
- “看它长大”播放整体缩放的成长示意，不是正式植物阶段系统。
- 混合版和 3D 版可小幅转动视角、调整俯视角和回正。
- “放到真实桌面”在当前显示器底部打开 Windows 原生桌面层，位于桌面图标之下、壁纸之上，控制台的选择同步到桌面。花园始终穿透鼠标；只旁听桌面空白处的单击／双击，图标、其他应用及拖拽优先，不吞输入。控制台的“收起桌面花园”关闭小样；关闭控制台也会清理原生画布和本地服务。可用 `node scripts/preview-garden-styles.cjs --desktop` 直接打开。

## 实现与美术边界

- `experiments/garden-style-lab/` 是独立页面，使用仓库已有 Three.js；本地 HTTP 只监听回环地址，仅提供小样、Three.js 和植物素材目录。
- 2D：Canvas 草坡、独立植物图片与简单摆动。
- 混合版：真实草坡几何＋带透明贴图的分段植物平面，顶点随风弯曲，能够展示前后遮挡。植物没有完整背面；平面固定朝向，旋转时能看出纸片性质。幼苗也使用平面图。
- 3D：程序搭建的圆润茎、叶、草莓、花和蘑菇，实时光照。不是 Tripo 成品，也没有声称还原概念图。铃铛花等形体仍较简化，后续可替换精细模型。
- 三种方向使用同一套样本摆位及植物类别。变异只演示外观颜色／材质变化；小兔只是小样陪衬，没有接入正式桌宠。
- 三张 AI 植物 PNG 在 `assets/concepts/garden/plants-v1/`，透明背景，生成工具为内置 image_gen，提示词同目录保存。它们既用于 2D / 混合版，也可以交给用户作 Tripo 单株参考。浏览 `/references.html` 可逐张保存。
- 概念图仍在 `assets/concepts/garden/2026-10-11/`。小样未改正式花园布局、存档、规则或客户端构建，不读写正式账户，也不调用付费建模接口。

## 验证

`node scripts/preview-garden-styles.cjs --verify` 使用独立临时 Electron 档案、真实窗口输入与截图，检查三方向、新手／后期、点击、变异、成长示意、转动回正、透明桌面窗口、工作区底边定位和状态同步、超宽桌面植物完整显示、多次切换资源释放、关闭微风后停止持续绘制及交互唤醒、680×640 布局。

结果与截图：`output/garden-style-lab/verification.json` 和同目录 PNG。验证不代表长时功耗测试，也不代表正式种植经济或 Tripo 模型接入验收。

## 2026-10-12 桌面图层调整

使用离屏 Electron 渲染及 `scripts/garden-desktop-host.cs` 原生 GDI 画布。每帧 PNG 有背压，最多 18fps；渲染器不显示、不置顶。Windows 11 的 Progman 子窗口顺序验证为 SHELLDLL_DefView → 花园 → WorkerW；Explorer 重启或层级改变时自动关闭画布。只对底部范围观察鼠标按下／抬起，始终 CallNextHookEx，拖拽不触发；WindowFromPoint 排除应用，UI Automation 排除桌面图标及文字，无法判断时忽略。首次启动本地编译辅助程序需要几秒。

完整检查通过三种收获及重复收获保护、图层、帧传送、隐藏渲染器和原有布局等回归。`--verify --verify-desktop` 另验证前台应用点击被过滤、原生坐标桥接摇晃和收获状态同步，结果在 `desktop-verification.json`。坐标桥接使用注入事件；真实鼠标旁听及图标点击仍需桌面实用检查，不能把离屏截图当作最终桌面合成证明。未完成长时功耗测试。
