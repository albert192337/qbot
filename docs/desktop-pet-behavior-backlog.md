# 桌宠行为后续规划脑包

独立规划文档。用户明确要求：`desktop-pet-behavior-inventory.md` 是重要的已实现行为表，本轮不编辑、不重排、不用规划覆盖实现现状。本文想法不能被当作已实现能力。

## 本轮优先：注意与活动衔接

- 聊天输入时倾听：只感知本应用聊天框的输入活跃状态，不采集其他应用输入内容。停手、失焦、关闭输入框后恢复；请求回复期间可继续倾听。优先已有倾听/点头素材，没有时用安静动作和轻微姿态变化。
- 回到电脑时招呼：电脑空闲至少5分钟或锁屏后重新操作，短暂招呼；10分钟内不反复触发。首次启动、普通停顿、隐藏时不补演。
- 实际访客到场时回应：已有房间里新访客完成角色加载并可见后短暂招呼；刚进房间的成员快照和重复通知不连发。已有邀请/双方授权规则保持，不擅自邀请、接受或创造访客。
- 被打断后继续：保存当前活动及剩余播放轮次，输入、招呼、双人互动结束后恢复同一活动。视频/GIF/Spine在恢复时从该动作片段开头接续，尚不保存精确帧或书页状态。新指令、换角色、隐藏、拖拽、场景不再适用或超过10分钟会放弃旧活动。
- 拖拽、花园表演、正在双人互动、手动一起工作、窗沿停靠及明确动作播放期间优先原交互；不排队补演过期招呼。倾听和招呼不调用模型、不生成新媒体、不增加说明小字，实际触发与恢复写入行为日志。

## 待后续设计与实现

| 想法 | 期望表现 | 需要进一步确定 |
|---|---|---|
| 回自己的小角落 | 玩完后回到喜欢的地方，慢慢形成固定休息位置 | 多显示器、用户移动后的偏好更新、避免挡窗口 |
| 试探着找你玩 | 拿出小球看看你；没回应就自己玩 | 频率、用户拒绝后的冷却，不连续索要关注 |
| 自己找乐子 | 纸飞机、叠石头、追影子；失败后停一下再试 | 道具素材、阶段衔接、三类角色表现回退 |
| 角色之间的即时反应 | 被打哈欠感染、转头围观、给熟人让位置 | 感知范围、关系依据、禁止循环互相触发 |
| 珍惜某件小东西 | 把收到的花留在角落，之后看看、整理 | 道具持久化、来源、数量上限与清理方式 |
| 两个角色的小习惯 | 与某伙伴常喝茶，之后会拿出茶杯提出邀请 | 真实互动记忆、关系变化、仍逐次授权 |
| 连续活动更细的进度 | 看书暂停后回原页，拼图接着未完成部分 | 需要独立活动进度；不能把动作重播冒充精确续接 |

统一表现原则：优先姿态、停顿、位移、已有表情和道具；不加“我正在注意你”等说明小字。需要授权时使用已有短句弹窗。后续每项单独验收后再讨论是否更新重要行为表。
