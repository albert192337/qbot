# 世界旅行与旅行朋友圈

入口：桌宠底部新增地球、相册图标；花园窗口也有世界旅行、朋友圈入口。

## 当前可玩内容

- 京都、巴黎、海岛三站。每站五类体验，每类三步；步骤名称不同。京都每类价格 80 / 140 / 220，巴黎 220 / 360 / 540，海岛 400 / 650 / 950。使用现有花园金币，数值为首版试跑配置，未宣称达到每日 3～4 次回访的最终经济平衡。
- 完成一站 15 步才能解锁下一站，不另收车票费。旧站免费回看，体验不能重复付费，最后一站显示后续目的地准备中。
- 地图、城市和照片采用本地 SVG 插画。体验完成即保存回忆；照片合成当时角色的闲置 GIF 或原图，数据随回忆保存，换角色不会改变旧照。没有可用素材时使用默认标记。
- 朋友圈是本地旅行记录，可以点赞；不会向真实社交平台发布。每次体验记录照片，日记按本地日期和角色合并为每天一篇。
- 先保存事实日记，有 Ark Key 时异步由模型按角色人设润色，参考当天最近三条用户聊天；失败保留事实正文。过期模型返回不会覆盖包含更新体验的日记。请求和输出进入 LLM 调试日志，照片不发送给模型。
- 旅行体验同步共同回忆，供后续对话检索。当前日记在旅行体验发生时更新，未实现无旅行日的独立自动日记或全量桌面活动归档。

## 存档与验证

旅行状态作为 garden-demo.json 内 state.travel 的可选字段，旧存档按首次体验懒初始化。扣款、进度、事实日记和回忆使用花园原有串行原子保存；客户端传入预期步骤，拒绝重复点击、跳步、越站、余额不足。

- `app/test/travel.test.ts`：扣款、重复点击、异常输入、地图门槛、旧存档与损坏存档。
- `app/test/travel-memory.test.ts`：日记合并、日期隔离、人设与事实、离线保底；模型全部模拟。
- `scripts/test-travel.cjs`：隔离存档真实 Electron 鼠标点击、并发扣款、持久化、点赞、下一站、小窗口与照片截图。仅可选读取当前桌宠素材作为图片测试样本，不改真实存档，不调用模型。

## 后续内容边界

本版未增加新的当地植物、真实纪念品库存、独立体验动作素材或永久桌面背景切换；这些需要后续内容配置与美术。未来增加城市须同步校验存档结构并迁移 progress 数组，不能直接变更长度使旧旅行存档失效。
