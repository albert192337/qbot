# 3D 草莓种植试版

2026-09-22 更新：3D 模式已加入轻量 Tripo 菠萝，允许草莓与菠萝播种；成熟菠萝、收获物和词条支持见 [菠萝模型说明](./pineapple-3d-model.md)。以下保留最初草莓试版的实现记录。

工具抽屉 → 种植画面 →「2D 手绘种植 / 3D 草莓种植」。土地页顶部有相同快捷切换。设置键为 `gardenRenderMode`，默认 `2d`，写入原设置并广播到已打开的花园窗口。运行旧版桌宠需重启后使用新增入口。

两种画面使用同一份花园数据。切换不兑换、不清空、不迁移土地、种子和收获。3D 模式只允许草莓单次/批量播种，UI 与花园服务都限制；已有其他植物继续手绘显示，可照常施肥、收获。其他种子仍留在背包，切回 2D 后可播种。

## 外观

- 幼苗、叶丛与白花、青果、成熟果四阶段，对应生长比例 0.22、0.55、0.8；沿用当前规则的实际成熟时间和可操作状态。
- 模型包含低矮土垄、土粒、三出锯齿叶、叶脉、弯曲果梗、白花和带籽点的悬垂草莓；再生期间保留成年叶丛。
- 采摘后在收获篮中显示独立 3D 果实；种子纸袋保留原画，草莓徽标使用 3D。
- 支持普通、巨大、双生、若干染色、水晶/冰冻、玉润、虹彩等材质及基础附件。高级词条外观仍是简化试版，不代表每种词条最终美术；数值、标签和繁育规则沿用原系统。尚未揭晓的果实继续遵守现有遮蔽规则。
- 原手绘资源与 DOM 保留。WebGL 初始化失败或上下文丢失时恢复原画。

## 渲染与生命周期

`strawberry-3d.js` 使用一个共享 Three.js WebGL renderer，各模型输出到自己的透明 Canvas，保持原 DOM 的遮挡、弹窗、点击与穿透逻辑。不为每株创建 WebGL 上下文。动态最多约 20fps、DPR 上限 1.5，视野外不绘制，隐藏页面暂停；减少动态效果时只在尺寸改变等必要时绘制。移除节点释放对应几何/材质，退出释放环境贴图和 renderer。

土垄是草莓模型的一部分；原有土块仅在该模型成功挂载后隐藏。透明画面不真实折射桌面壁纸。

## 验证与试种

`scripts/test-garden-3d.cjs --show` 使用 Electron、真实生产 renderer 和真实种植规则，但使用临时目录与内存存档，禁止联网；不读取/改写真实花园。成功后打开土地页及透明桌面地块，可继续试种，关闭土地页同时关闭试种地块。

覆盖：五种地块显示（含空土）、其他植物保留、双窗口实时切换且数据不变、仅草莓播种、施肥、收获、再生、收获篮。结果和截图位于 `output/garden-3d/`。

花园 service 测试覆盖 3D 拒绝其他种子且不落盘/不扣种子、接受草莓、切回 2D 后恢复其他品种播种。长期多窗口功耗尚未测量。
