# 桌宠摸摸（2026-09-25）

## 交互设计

鼠标在角色显示区域内，不按键，沿任意方向来回移动：1.4 秒内累计移动至少 70 DIP、两次有效反向（每段至少 12 DIP）后触发。静止、单向经过、细小抖动、按键拖拽、操作按钮不计入；离开、失焦或隐藏清空手势。两次独立摸摸至少间隔 8 秒；持续抚摸只续期，不重复触发。

触发后进入持续摸摸状态，光标变成粉色小手。持续移动鼠标续期，停止移动 1.5 秒、离开角色、按键、失焦或隐藏时退出；整个状态中循环播放被摸动作和轻蹭动画，退出后恢复当前待机/同步动作。同一次摸摸只记录一次聊天，续期不受新互动的 8 秒冷却限制。角色轻轻左右蹭动，优先复用已有开心/微笑/感谢表情包或视频；无匹配动作时沿用原素材，蹭动本身提供反馈。不开付费生成任务，不新增角色素材要求。减少动态效果时保留小手、取消蹭动。不叠加遮挡角色的气泡或文字。

自己的角色和同房房友均可摸。隐藏、加载失败、离场、拖动、双人表演和培育期间不抢占动作；本机非空闲时不触发。房友同步不被摸摸永久覆盖，结束恢复最新状态。

## 聊天与同步

单机只反馈动作。本地试演只写会话聊天。真实房间发送独立摸摸请求，服务端从连接身份与同房在线成员确定双方昵称，生成「甲轻轻摸了摸乙，乙开心地蹭了蹭小手。」；摸自己显示「甲摸了摸自己的桌宠」。沿用房间最近 50 条记录与持久化，不发世界聊天。关闭聊天时拒绝记录/联机互动；客户端明确报告失败。

服务端每个发起者至少间隔 8 秒，拒绝跨房、离线目标及过期房间请求；客户端冷却只是即时预挡。实时事件只在当前房间驱动被摸角色，历史回放不触发动作。旧服务不支持时提示更新服务，不伪造成功。

## 已实现与验收

- 手势逻辑：app/src/shared/petting.ts；共用反馈：renderer/pet/petting.ts、petting.css；本机状态机与房友 NetworkDriver 接入各自入口，开心动作不可用时保持当前素材轻蹭。
- social.pet()/onPet() 经主进程验证发送窗口确定目标，renderer 不能指定任意成员；服务端通过 hello 的 petting:1 协商能力。互动消息用 interaction: petting 标记，记录仍支持原有撤回/举报。
- 16 项相关单测通过，App 类型检查与构建通过。脚本 test-petting-server.cjs 启动独立回环服务验证真实请求、两端广播、身份字段防伪、同房/离线目标、跨连接冷却、聊天关闭与重启持久化。
- test-petting-ui.cjs 用真实 Electron renderer/preload/社交 IPC 验证自己和房友，检查单向划过/按键不触发、小手和轻蹭、冷却、聊天记录、减少动态效果和按键取消。截图位于 .superpowers/petting-preview/。角色素材为隔离预置角色，不使用真实用户存档。
- 验证范围：本机 Windows 隔离实例。公网服务未部署，安装包未发布，用户正在运行的实例未重启；联机使用需更新房间服务与客户端。

## 持续状态修正

原实现固定 2.4 秒 CSS 动画和 playOnce 已改为无限 CSS 动画与 playLooping，生命周期由摸摸状态控制。每 500ms 最多一次续期，1.5 秒无移动退出，隐藏/离开/按键立即退出；本机待机计时在摸摸期间暂停，结束恢复，房友恢复最新同步状态。服务 petting:2 支持 keep/end，续期只能延长该连接刚发起的同房同目标互动，不追加聊天；客户端失联时动作自动过期。旧 petting:1 服务仅能持续本机视觉，完整跨端持续需更新服务。

持续状态验收通过：App 类型检查与构建，test-petting-server.cjs 的续期/结束/无额外聊天测试，以及 test-petting-ui.cjs 中房友连续轻晃超过 8 秒和自己连续轻晃 4 秒的真实视频 loop 检查、移出恢复待机。未自动重启真实实例。
