# 通用 Q 版 Spine 换皮规范

2026-09-26：用户确认小黄鸡兜帽少年 v6 效果，并要求后续角色沿用本规范。

## 已确认的视觉要求

- 复用提供的 Spine 4.0.64 骨骼和动作。角色为大头、小身体的二足 Q 版人形。
- 头、脸、头发和配饰轻微朝画面左侧，与原骨架一致；避免在微侧身体上放完全对称的正脸。近侧右耳和脸颊适度可见，远侧收窄。
- 保留新角色自己的发型、服装、颜色和标志性配饰，不能沿用模板帽子或头发冒充换皮。
- 默认独立短豆豆眼、短线嘴；五官轴随脸的朝向调整，远眼略窄，闭眼沿用相同位置。新参考另有明确表情要求时再单独适配。
- 头部等比缩放，不横向拉伸。按新脸的留白实际校准眼距、嘴高，不能直接认为旧坐标适用。
- 下巴、脖子、衣领必须有遮挡搭接，动态不露背景缝。v6 基准把躯干上缘上移 4 个图集像素、腰线不动；这是校准起点，不是任意角色通用常数。

## 部件与播放

- 头发/头饰/无五官脸底合为头块，另有躯干、两臂、两腿，以及独立双眼、嘴和闭眼附件。
- 生成真实透明部件图；按透明间隔切割并检查完整性，禁止按假定等格裁切而截断下巴或手脚。
- 将部件装入原图集 UV，复用加权网格；屏蔽旧鼻、眼、眉及未适配饰品，防止原角色漏出。
- 贴贴动作保留已验证的膝目标校准：髋脚线段投影 35%–65%，侧向偏移最多 4 骨骼单位；每帧重置基础值，避免累积。
- 新角色用独立资源名和预览入口，保留此前已认可的角色。
- 第一版范围包含长发、裙子和袖子。允许简化：后发放身体后并随头整体运动；裙子随骨盆/腿部做简单遮挡，袖子随手臂，不要求独立物理摆动。仍须检查侧躺、抬臂和双人动作穿插。此为范围要求，现有吴邪/张起灵样例尚未验证长发与裙子。

## 验收范围

### 每次换皮必须执行的视觉检查

1. 装配前放大检查部件：躯干不得包含重复袖子/手；头块不得包含第二条脖子；手臂端点、手腕朝向与模板一致。发现错误先修素材。
2. 每个角色有自己的 `*-calibration.json`；五官位置必须依据新脸的留白与透视校准，不能借用其他角色参数后直接宣布合格。开眼和闭眼一起调整。
3. 输出七动作周期四分位截图，并用 `scripts/spine-lab-review.py` 生成大图；逐一查看脸、颈、双肩、肘腕、髋膝踝。小尺寸整页截图不足以验收。
4. 单独对照用户参考检查脸型、视线、眼距、嘴部和手部姿态。记录已确认的问题与未覆盖范围；数值检查与视觉结论分开报告。
5. 只向用户提供最新校准后的预览；旧草稿截图不得冒充修复后的证据。不要用“全部动作正常”概括抽帧检查。

检查待机、走路、跑步、开心、侧躺睡觉、喝茶姿势和贴贴，覆盖周期关键帧。重点看脸部朝向、颈肩接缝、髋膝踝和层级遮挡。矩阵有限值检查不代表视觉合格。

这些素材仅用于本地换皮实验；尚未接入正式桌宠播放器。喝茶道具、双人站位编排及完整表情库需要单独适配。
