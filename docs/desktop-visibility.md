# 桌面隐藏、房友操作与屏幕贴边

2026-09-25，按本次讨论确认的交互实现。

## 使用方式

- 自己的按钮栏在天气右侧增加眼睛按钮。隐藏所有角色和附属界面，但自己的整排按钮保留原位；再次点击恢复。托盘也提供隐藏/显示入口。
- 隐藏期间禁自动气泡、留言、声音、天气背景及新窗口弹出。保留连接、后台生成与自然种植计时；角色参与的田间表演/培育沿用现有暂停、离开流程。
- 主动点击保留的按钮可以打开相应面板；恢复角色不会自动重开聊天、设置等大窗口，也不会重放旧气泡。单独隐藏的房友保持隐藏。
- 房友的花园、互动、隐藏按钮在悬停或单击时出现，离开整个操作区域 500ms 后收起。互动面板提供现有八种互动图标，显示等级锁；真实邀请和本地试演沿用各自后端校验。拖动不触发单击，Escape/失焦关闭面板，同时只展开一个房友的操作栏。
- 房友隐藏只影响本机；按 memberId 保存到 userData/desktop-hidden-members.json，不发送房间消息、不拉黑、不退房。成员列表显示「显示在桌面」恢复入口；重连和换外观不重置选择。
- 手动拖到显示器工作区左右边缘 26 DIP 内，松手后进入窥探；多屏接缝可直接通过。复用现有 idle 素材，侧倾并移出画布，露出部分脑袋。只播待机，不主动气泡或发声；点击或拖出恢复。第一版没有生成专用扒边动作，特殊造型的露头效果会随原素材不同。
- 窥探时隐藏名字和提示，悬停露头区域显示自己的按钮栏；全局隐藏仍保留按钮栏，恢复后保持原窥探侧。房友也支持手动贴边。

## 实现边界

`main/desktop-visibility.ts` 是本机会话显隐权威，集中跟踪窗口并在 show/showInactive/restore 调用前检查许可，避免 ready-to-show、重连和延迟请求重新展示。普通面板隐藏后保持收起，显式打开才解除限制；桌面花园和原房间场景按原可见状态恢复。

本体窗口保留 HUD，renderer 对角色及其附属内容用 display:none 隐藏，避免 video 的显式 visibility 覆盖父级隐藏。初次加载与刷新先空白，拿到当前显隐状态才显示。隐藏/窥探时只有按钮及露头区域接收鼠标，其他透明区域穿透。

主进程统一静音，renderer 中断说话、走动、一次性演出；播放器暂停时取消完成计时与解码重试，资产保留供恢复使用。普通生长计时不依赖角色动画。自然天气的画面停止不改变天气结算。

贴边使用固定逻辑尺寸移动，避免 Windows 分数 DPI 往返扩大窗口；屏幕移除和工作区变化重新夹取位置。主进程的房友重排保留已有贴边位置。

## 验证入口

- `app/test/desktop-visibility.test.ts`：左右吸附、正常位置、多屏接缝、负坐标、部分接缝。
- `app/test/player.test.ts`：隐藏时暂停并取消重试/完成事件、显式恢复，保留既有播放回归。
- `scripts/test-desktop-visibility.cjs`：生产 IPC、窗口与实际 renderer，临时数据目录、预置角色、禁外网、本地试演。覆盖按钮、八种互动与锁定、本地送心、单独隐藏/重入/成员列表恢复、恢复播放、全窗隐藏、晚创建窗口、隐藏中主动打开面板、静音、旧气泡不恢复、左右窥探、鼠标点击/拖出、尺寸不变、隐藏中刷新及房间模式恢复。
- 截图：`.superpowers/visibility-preview/`。脚本仅替换定时原生壁纸时钟；没有连接真人房间、Steam 或付费模型，没有改真实存档。
- 尚未以多台实体显示器和所有用户角色素材逐一验收；多屏接缝有几何测试。

运行：先在 app 目录构建，然后从仓库根运行 `node scripts/test-desktop-visibility.cjs`。

本轮验证：36 项相关单测、App 类型检查与构建通过；scripts/test-desktop-visibility.cjs 验证原位恢复、重新加入、全局隐藏、外侧心愿矩形与关闭后重载不重复；scripts/test-desktop-overlays.cjs 验证跨窗口互斥与手动关闭当天抑制。均用隔离存档。

## 房友互动菜单停留（2026-09-25）

悬停操作栏仍在离开后延迟收起，但显式点开的互动菜单在加载、选择及提交期间保持展开，不被角色到操作栏的 pointerleave 或旧 500ms 计时打断。入口以 aria-busy 表达加载，不禁用当前焦点按钮。选完、再次点击入口、点击外部、Esc、失焦/隐藏或跨房友互斥时收起。回归 scripts/test-peer-controls-ui.cjs 使用真实房友 renderer 与试演 IPC，已验证八项菜单停留及实际动作执行。
