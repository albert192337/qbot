# PixiJS 互动特效试做

2026-09-28：为桌宠新增摸摸爱心和升级星光，使用 PixiJS 8.21.0。

视觉修订：爱心去掉描边，降低密度、尺寸和不透明度；升级改为 5 处错时轻闪，轻微上浮，取消整圈放射运动，星光也去掉描边。

## 行为

- 摸摸仍由现有手势和互动事件触发；成功后在鼠标位置发射爱心，房友互动从角色上方发射。停止、拖动、隐藏和切角清理。
- 沿用已接受的 `garden:interaction` 经验事件，只在角色等级提升时播放星光；普通经验增长、其他角色经验不播放。特效不修改经验、背包或联网协议。
- 同一角色窗口共享一张鼠标穿透的透明画布，按角色舞台的位置和尺寸布局。角色视频和 Spine 播放沿用现有逻辑。
- 第一次互动才懒加载 PixiJS、创建 WebGL 画布；30 FPS，最多 64 个粒子，分辨率最高 2 倍。粒子耗尽即停止 ticker 并隐藏画布，页面退出销毁纹理和渲染器。
- 减少动态效果、隐藏、侧边收起时取消效果；取消发生在异步加载中也不会迟到补播。初始化失败时保留原有互动。

## 试用与验证

构建后运行：

```powershell
node app/node_modules/electron/cli.js scripts/test-pixi-effects.cjs --preview
```

独立试用窗口使用预置小龙和真实桌宠页面，按钮触发离线模拟事件，不读取或修改正式存档。可用 `QBOT_QA_ASSET_DIR` 指定只读角色素材目录。

去掉 `--preview` 运行隔离 Electron 验收，结果与截图输出到 `output/pixi-preview/`。覆盖真实摸摸手势、懒加载期间取消、鼠标穿透、经验阈值和角色匹配、缩放、空闲停止绘制、切角、隐藏及减少动态效果。

验证空闲 ticker 停止不等于整个客户端零资源占用；角色视频仍会播放，长时间多角色与不同显卡环境尚未验收。
