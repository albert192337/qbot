# 桌边草地

2026-10-12，正式花园接入用户选定的第二方案：连续 3D 草坡和二维植物。工具栏“桌边”选择新版，“原版”恢复旧花园；旧 2D／3D 仍可互切。管理页底部及开发设置也有入口，选择保存在本机。

## 操作与数据

空种植点打开对应地块；单击植物摇晃；双击可收获的成熟植物走原来的正式收获接口。未成熟、待培育和标记保留的植物打开详情，访客培育期间不操作本人的土地。双击先校验最新植物 ID 和阶段，忙碌时忽略重复输入。

种子、实际地块、库存、成长、经济及服务端协议保持原链路。新版覆盖全部正式物种的手绘素材；显示原有幼苗、生长和成熟阶段。神秘作物只送安全描述给场景；变异用颜色、大小、双生和光点表达，染色沿用现有色相。不是三种概念花替换正式物种，也没有新增或付费生成模型。

## 桌面集成

- 正式 strip 保留工具栏，新画面由独立离屏页面绘制，原生 GDI 画布位于 Explorer 图标下方、壁纸上方。支持独立桌宠和已有房间模式，不必切换当前角色展示。
- 点击观察器不吞鼠标事件，排除拖拽、图标和前台应用。透明工具栏可能被 `WindowFromPoint` 返回，因此按原生透明标记继续检查下层真实窗口；图标判定只读取 Explorer 图标的矩形，不读取名称或文件正文。
- 收起、隐藏、切回原版、休眠、退出等清理画布及离屏窗口。启动取消带版本校验；原生进程跟随宿主退出。显示器变动重新定位。启动或绘制失败保留原版切换入口。
- 18fps 上限、PNG 帧背压、减少动态时按需绘制。贴图按显示版本缓存并释放，重复同物种共享贴图。尚未进行长时间 4K 功耗或所有 Windows 版本验收。

主要代码：`app/src/shared/garden-hybrid.ts`、`app/src/renderer/garden/hybrid-scene.js`、`app/src/renderer/garden-hybrid/`、`app/src/main/garden/desktop-layer.ts`、`desktop-host.ts`、`desktop-source.ts`。

## 验证

- 32 项定向测试通过：安全显示描述、点击规则、显示通知、旧场景布局、v0.4 经济，以及正式服务的播种、显示切换保存、记录和重启相关用例。
- `node scripts/test-garden-hybrid.cjs`：正式渲染页、预加载桥、原生画布与本地正式种植规则，隔离数据；验证真实收获结果、重复保护、播种同步、保留及未揭晓规则、新旧往返资产一致、窄屏、减少动态、原生窗口命中分类、取消启动及清理。
- 原版 `scripts/test-garden-scene.cjs` 的 12 类实际窗口回归通过。类型检查和客户端构建通过。
- 实例切换已验证房间模式下显示新版、工具栏旧版入口存在、离屏窗口不显示及不置顶，切换前后作物／种子／果实／金币一致。未对真实账户播种或收获，旧独立小样已关闭。
- 报告在 `output/garden-hybrid/verification.json`、`live-verification.json`，原版报告在 `output/garden-scene/result.json`。测试的桌面点击坐标注入与真实鼠标物理点击区分；离屏 PNG 不能作为最终桌面合成截图的证明。真实 Explorer 层级另用原生窗口树检查。

扩大测试时，旧 `garden-progression` 五项旧等级解锁／喂食断言和 `garden-service` 两项旧陪伴开箱断言仍失败，与既有 v0.4 固定地块、停用陪伴开箱规则冲突；本次未修改这些规则或弱化测试。定向测试不等于全仓库测试全部通过。
