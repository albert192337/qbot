## 规则待确认及后续实现

- [ ] **U04 · 每角色独立房间**：当前仍使用全局房间存档。需确认旧房间首次归属、家具库存是否跨角色共享、哪些基础家具可复用，再实现迁移；不复制有限库存。对应 C01。
- [ ] **U05 · 聊天补齐**：当前支持文字与普通文字表情，尚无图片消息和收藏表情；公开发言仍打开旧多人聊天流程。待确认协议、历史留存和公开聊天相关规则后补齐，同时保留当前角色对白、轻量输入框及可收起记录窗口。对应 C04、C07、C08。

- [ ] **U07 · 每日玩家目标**：已展示现有玩家目标，尚未新增每日目标、刷新和奖励规则。生成任务继续归角色页。对应 C03。

其他规则边界：扭蛋奖池已按具体内容展示并将外观优先排列，概率、保底没有调整（C05）；聊天记录目前为每角色最近 24 小时、最多 40 条（C07）。旧高级功能的去留按 C06 逐项核对，不将入口清理扩大为资产或接口删除。
