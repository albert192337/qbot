# 陪伴角色体验自测 · 2026-09-25

## 结论

目前更像两三个朋友陪你坐一会儿的小屋，已有温暖感，热闹程度温和。世界不再空白，进房有人欢迎和闲聊，表达疲惫会得到相关回应，主动互动能被看见。还不是能自由长聊的真人社群；主题库较小，长时间逗留仍可能感觉到脚本重复。本次是代理的体验判断，不等同真人玩家评价。

## 实际走查

使用临时玩家存档、回环房间服务和生产社交/房友 renderer。从公开装扮市场只读下载六个真实角色包：豆包、宗辉、秦彻1、小方、未命名、小黄狗·表情包；未部署公网、未修改真实玩家存档。

从世界广场选择花园茶会，看到苔苔与橘子汽水。在真实桌面房友窗口确认两名市场角色的视频加载并推进播放时间。检查其花园公开状态，品种、成长进度和经验有区别。全过程留存截图与服务器时间戳的聊天记录。

实际聊天片段：

- 进房：苔苔「来啦，给你留了个晒太阳的位置。」
- 稍后闲聊：「我给草莓留了块向阳的位置。」
- 玩家先说「大家好」，约三秒后补「今天有点累，想在这里歇一会儿」。
- 约五秒后：苔苔「辛苦啦。想说说哪件事最累，还是先在这里歇一会儿？」没有抢先回过时的招呼，原本房友之间的后半句闲聊也取消。
- 聊天小窗直接出现双人邀请，点击「一起玩」后服务器接受、邀请卡消失。
- 玩家说「谢谢，我想安静一会儿」，橘子汽水回应「好，那就安静陪你待会儿。想聊的时候再叫我。」随后连续观察 65 秒，没有新的陪伴角色消息。

## 自测后修正

1. 连续短消息合并为待回复内容，以最新一句为准，取消未发送的旧欢迎语。
2. 玩家发言取消正在排队的房友闲聊；表达疲惫时不照常插入无关对白。
3. 支持请求安静，暂停主动闲聊与邀请；再次主动聊天可恢复。
4. 互动邀请从朋友页提升到社交/聊天窗口内，提供接受/拒绝，不打开遮挡角色的新桌面提示。
5. 修正「想和你送小心心」为自然邀请语；压缩小窗邀请卡，保持最新消息可见。
6. 世界筛选默认收起，让房间列表优先展示；首次世界招呼提前到短等待后出现。
