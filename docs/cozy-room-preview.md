# 奶油小屋：可运行的 2.5D 试住样板

2026-09-10。房间和六件家具已实现为独立绘制/交互对象，不是整张概念图当背景展示。固定视角，不支持自由旋转镜头。

## 进入与操作

更新后的 App：故事小屋 → 起居室 → 布置小屋 → **试住奶油小屋**。原房间右键也有同名入口。独立窗口不会切换当前桌宠或房间连接。

- 拖家具改变位置，点家具架选中，收纳后可再次放回。
- 选中后在画布上用方向键微调，Shift 加大步长；可镜像换朝向。
- 点空地让桌宠移动，按地面网格绕开家具；无走路素材时仍播放已有常态，不伪造专用行走视频。
- 切换午后/落日/夜晚，比较接地柔影和暖灯；可移除地毯。
- 角色下拉框只预览本机角色，不激活或上传角色。
- 显式点击保存，使用专用 `qbot.cozy.preview.layout.v1` 存储；未保存变化关闭后放弃。恢复初始布置须再点一次，保存后才覆盖已存预览布局。

## 体积感处理

房间壳采用厚墙、圆角木平台、暖木地板和统一视角。家具是饱满的软质卡通图集：沙发、茶几、蘑菇灯、书架、盆栽、培育台。透明源图保留，不对既有角色做重新生成。

运行时为家具和角色添加椭圆接触柔影，按脚底纵向位置排序，角色在家具前后会正确遮挡；夜晚加入冷色环境覆盖和局部暖灯。精灵图集只读取每格主连通轮廓的包围盒，避免生成素材跨格碎片进入显示范围。图像按 Canvas 裁切显示，源文件不被改写。

这仍然是 2.5D：大部分物体光影烘焙在图片里，灯光是氛围合成，不是完整物理照明；镜像也不是家具真正的三维旋转。坐在沙发、多人同步摆放、壁面挂件与任意角色的脚底锚点标定留在后续。

## 验证

- App TypeScript 检查与构建通过。
- `app/test/cozy-room.test.ts` 三项：不可信存储恢复、坐标转换、家具避障路径。
- `scripts/test-cozy-room.cjs` 使用真实 Electron、preload、透明素材与角色播放器验证六件家具、收纳/保存/重开、三时段、键盘/指针拖动、800×680 小窗口、无正式库存/角色激活写入。
- 实测小青、线条小白狗、秦彻人形现有动画。小白狗当前素材自带凳子，样板没有移除这一原有内容；视觉适配不意味着自动生成了新的坐卧动作。
- 截图位于 `.superpowers/cozy-preview/01-day.png`、`02-night.png`、`03-sunset.png`、`04-small.png`、`05-line-dog.png`、`06-human.png`。
- 未运行整个仓库回归，也未验证完整多人房间；本次改造不接入经济、研究或抽取系统。
