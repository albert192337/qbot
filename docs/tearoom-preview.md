# 窗边茶室：固定位置的 2D 角色试住

2026-09-26。独立视觉样板，比较现有装扮站角色放进近正面手绘场景后的比例、接地与家具遮挡。

## 进入

- 构建后的 App：奶油小屋顶部 → 试住窗边茶室。
- 本机独立试住：`node scripts/preview-tearoom.cjs`。只读 `%APPDATA%/@qbot/app/characters` 中的现有角色，优先展示 `market-*`；窗口关闭退出。不激活桌面角色，不写家具库存、不入房、不上传。
- 首次使用需 `npm run build -w app`。之后仅更新样板可用 `node scripts/build-tearoom.cjs`，保留其他页面输出。

四个位置：沙发旁、茶桌后、窗边、地毯上。每个位置独立选择角色和已有动作、大小（65—145%）、脚点微调（±45 原图像素），可留空。点“收起布置”看完整画面；“保存照片”导出不含界面的 PNG。显式“记住这次安排”保存独立 localStorage；隔离启动器每次新建预览档案，正式入口则随当前档案保存。

## 实现与边界

- `renderer/tearoom` 使用 1536×1024 固定镜头，四个 Player 在同一 Canvas 合成。茶桌前景用原画轮廓蒙版重绘，遮住后方角色下半身，茶桌角色横向避开茶壶和花瓶。
- 按播放素材透明轮廓校准可见高度和接地，低频测量、同一媒体累积轮廓范围以减少呼吸造成的缩放抖动；阴影按可见宽度调整。30fps，页面隐藏暂停 Player 与绘制。
- 原画背景当前包含固定家具；家具不能拖动或更换，不声称是完整分层装修系统。背景由内置 imagegen 生成并按手绘风格修订，源图保存 `app/src/renderer/tearoom/art/afternoon.png`，提示词见 `tearoom-art-prompts.md`。
- 沙发位置仅在已有 `perch_sit` / `perch_lie` 时移到座面，其他动作留在沙发旁。没有生成新坐姿或移除原素材道具。当前本机角色没有验证专用沙发坐姿，需后续适配。
- 接入当前角色库，包括已下载的装扮站角色；未自动安装整个市场。首次实测包括市场“未命名”（像素章鱼）、“秦彻1”、“宗辉”，以及内置小青、本地小白狗。人形与背景更协调；像素画、粗线条、原素材自带长凳仍有明显风格差异。
- 当前是本地多角色视觉预览，不是多人联机同步、自由走路或真正的家具互动。

## 验证

`npx tsc --noEmit -p app`、App 构建、`node scripts/test-tearoom.cjs`。测试用隔离 Electron、现有本机装扮资产和生产 Player；禁止外网，确认四个视频实际播放、角色/动作切换、保存重读、空位释放、坏存储夹取、小窗口、实际 PNG 下载、零角色激活/家具写入。截图和检查结果在 `output/tearoom/`。测试安装角色要求至少两份 market 角色；可通过 `QBOT_COZY_REAL_CHARACTERS` 指定替代只读目录。
