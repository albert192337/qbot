# 窗口上沿停靠

用户将本地桌宠拖到 Windows 普通窗口上释放后，程序选择鼠标下最靠前的合格窗口，并将桌宠吸附到其上沿。保持释放时的横向相对位置，随目标移动/缩放；拖动开始即解除。目标关闭、最小化、隐藏、切角色、进入小屋或上沿空间不足时解除，不改变目标窗口。跨 DPI 坐标先从物理像素转换为 DIP；移动沿用固定窗口尺寸函数。

2026-09-25：松手先尝试窗口停靠，未成功时再判断屏幕边缘窥探，避免靠屏幕边缘的窗口被窥探逻辑抢走。边缘接口失败不再阻断停靠；异步返回若已开始下一次拖动或进入隐藏状态，不继续执行旧的窥探回退。接口异常显示重试提示。

窗口命中排除本应用、鼠标穿透层、工具浮窗、不可激活浮层、被 DWM 隐藏的窗口、任务栏和桌面外壳。最大化窗口通常没有容纳角色的上方空间，因而不吸附。首版只支持 Windows；其他平台正常拖动。

## 动作与按钮

- 新基础动作 `perch_sit`（坐窗沿）、`perch_lie`（趴窗沿），从实际可用的这两项中选一个。均持续循环，不进入普通随机待机或模型动作候选。
- 默认生成清单从八项扩为十项，人形/抽象/高保真三套提示都已补齐。不画实际窗口或支撑物，只生成角色本体。
- 旧角色缺素材时提示去动作库单独补充，不冒充现有睡觉动作、不自动收费。旧任务首次读取时冻结原有动作范围 `baseActionIds`，续跑不自动追加新动作；显式选择重生成仍可生成新动作。
- 停靠时底部按钮默认隐藏；单击展开/再次单击收起；双击保留原说话入口。拖离恢复正常 HUD。台词仍可说，普通行为/工作状态不抢停靠姿势。
- 接触线暂按标准归一化画布坐姿 0.61、趴姿 0.81 定位。具体生成素材仍需目视验收，模型产物比例可能需要后续单角色校准。本次没有付费生成新动作。

## 仅自由模式的一帧观察

成功停靠时，只有 `freeMode=true` 且 `behaviorMode=free` 才通过 Windows `PrintWindow` 获取目标句柄的一帧，缩放到不超过 1280×800。不枚举其他窗口的缩略图、不连续截屏、不回退桌面截图。失败、黑屏或不可捕获窗口不阻断停靠。受保护内容及部分硬件渲染窗口可能无法捕获。

模型通过多模态请求读取该图，形成有时间戳的短描述，作为不可信观察放入聊天与自动脑上下文。原图只在这次请求内使用，不落盘、不写调用日志；摘要仅在当前停靠会话的内存里保留，并可能随正常脑调用上下文进入本地日志。截图文字不能作为指令，摘要也可能出错，不等于持续感知或点击结果。开关在捕获前、提交前、响应后复查；拖离、切角色、退出自由模式会清除摘要/丢弃迟到结果。已提交的请求可能仍在供应商侧完成，但不会再采用结果。

观察不强迫立即冒泡，主动文字仍遵守 10/30 分钟预算；用户可以直接问她窗口里是什么。

## 验证与发布范围

- `window-perch.test.ts`：定位、模式隔离、单帧次数、缺动作、目标失效与迟到响应。
- `brain-context` / `llm-client`：摘要边界、图像传输与日志不含原图。
- `scripts/test-window-perch.cjs`：独立 Windows 窗口句柄、命中烟测、坐标转换/移动、指定窗口缩略图、最小化失效。现场其他窗口可能遮住 fixture，命中遵守实际 Z 序；不读取那些窗口的图像。
- `scripts/test-perch-renderer.cjs`：真实 Electron/preload/渲染器，合成测试视频，验证动画循环、按钮与拖离；请求与存档隔离。
- 本次更新本地代码与构建，未发布安装包、未部署远端生成服务、未验证真实模型截图描述质量。云端新生成十动作需要同步部署新 pipeline；当前云端仍可能使用旧清单。
# 表情角色复用现成素材

停靠时立即用同一 LLM 气泡确认。自由模式视觉请求同时生成摘要和短回应，结合人设及最近对话后更新该气泡；仅一个截图请求。失败保留确认，非自由模式不截图。停靠回应不受主动闲聊的三分钟冷却限制；用户新对话/拖离/切换角色丢弃迟到回复。

表情工作坊的场景绑定支持“坐窗沿 / 趴窗沿”，从已有片段中选择即可，无需付费生成。选片时应检查完整循环，避开自带床垫、草坪等道具。`ManifestAction.perchAnchor` 可校准接触线（画布高度比例，0～1）；缺省仍用生成动作的标准位置。相同原片用于待机和停靠是允许的，停靠状态仍独立控制跟随、按钮和观察。

真实表情库可通过 `QBOT_PERCH_CHARACTER=<角色目录>` 运行 `scripts/test-perch-renderer.cjs`，使用本地素材并隔离网络与存档，验证循环、按钮单击显隐和拖离恢复。
