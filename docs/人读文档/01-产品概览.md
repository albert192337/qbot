# QBot 产品概览

QBot 的定位是 AI 角色驱动的桌面陪伴与轻养成产品。角色陪用户工作和生活，花园与房间提供日常目标，真实玩家之间的来往让收藏和装扮有展示、回应与合作的意义。

以下是产品方向，具体落地范围见 [当前玩法与进展](02-当前玩法与进展.md)。

## 核心体验

用户拥有喜欢的角色，与它聊天、互动并积累共同经历；通过种植、天气变化和繁育培育植物，再用收藏和装扮表达偏好。朋友可以带来新的机会和共同目标，让日常有再次来访的理由。

理想的一次日常体验是：回到桌面，看一眼角色和花园，回应朋友，选择一件想做的事，安排下一轮生长，然后继续工作。

## 六个产品模块

| 模块 | 希望带给用户的体验 |
| --- | --- |
| 游戏与养成 | 种植、发现变化、收集与持续追求目标 |
| 角色陪伴 | 稳定的人设、适量回应、记住共同经历 |
| 社交 | 与真实朋友来往、合作、展示和建立关系 |
| 分享与邀请 | 把喜欢的角色和成果分享出去，邀请朋友参与 |
| 商业化 | 为审美、收藏、身份表达与便利提供可选择的商品 |
| 基础设置 | 控制成本、管理权限、可靠保存并稳定运行 |

## 产品设计中需要坚持的重点

真实多人是产品方向的重要部分。本地角色之间的表演可以增强陪伴，但不能代替不同玩家之间的交流与合作。

养成需要有看得见的成果和下一步目标。每个功能都应解释清楚：为什么进入、做什么选择、得到什么反馈、留下什么结果，以及为什么愿意再次回来。

商业化需要建立在用户已经理解商品用途、感受到审美和收藏价值的基础上。角色生成服务的收入与游戏内商品收入分别考虑。
