## 1. 已确认的产品方向

- 单人可以完整培育；多人参与缩短所需时间，并提高出好东西的概率。
- 发现带问号的可培育果实时，玩家应自然想到邀请好友或分享到世界频道。
- 邀请消息展示果实已有词条，并可直接进入该果实的培育现场。
- 丰富词条，充分借鉴原版数值结构，形成长期收藏、杂交与合作目标。
- 珍稀喷雾按类型随机赋予植物词条或颜色；每日商店刷新，自己和好友的货架有差异，支持去好友商店购买喷雾与种子。
- 在拜访、公共房间、好友列表中，都可以进入其他玩家的土地和商店。
- 每个角色独立成长，每日表达想吃的东西；点击头顶食物气泡，提交符合物种和词条要求的果实，获得经验并解锁更多双人互动。

本次新增模块详见第 13–16 节。文中的“现实商店每天刷新”暂按游戏内商店随现实日期每日刷新理解；首版以花园币购买，不据此新增现实货币付费。旧文“因子喷枪”统一接入新的喷雾道具系统，不再另建一套必定命中指定词条的道具。角色等级与物种等级分别保存；账号花园和每日货架不因切换角色复制多份。

完整体验循环：角色冒出食物心愿 → 查看需要的水果与词条 → 自己种植或去朋友商店找种子/喷雾 → 随机染色与词条培育 → 发现问号果实并邀请合作 → 收获并选择出售/收藏/繁育/投喂 → 角色升级 → 用新双人互动与朋友继续来往。

本稿对“提高好东西概率”的推荐落点：提高每名参与者额外奖励的优质概率，不重抽、删除邀请卡上已经展示的果实词条。主人保留果实，参与者独立获得奖励。问号表示最终形态尚未揭晓以及额外奖励未知，不表示已有词条未知。这是本稿的明确提案，尚未成为已实现规则。

选择轻量适配原版结构：比继续给现有无限堆词条模型加概率，更能形成组合目标；比一次引入原版全部经济和收费鉴定，更容易校准现有九物种和桌宠使用节奏。鉴定放后续阶段。

## 2. 数值出处与采用方式

标记含义：原版参考＝附件明确提供；项目适配＝本稿起测设计；待补配置＝附件不足以支持直接复刻。

| 系统 | 原版参考 | 我们的采用方式 |
|---|---|---|
| 因子槽位 | PartA 1、PartB 1、Global 2、Special 1 | 五槽：果实 1、果皮 1、挂饰 2、体型 1；语义归属为项目适配 |
| 天气变异 | 按幼苗期天气停留时长抽天气，再抽因子，成熟前统一结算 | 采用阶段结算，替换成熟留田无限追加天气词条 |
| 天气变异次数 | 泊松参数基础通常 1.1/1.2，参数 clamp 到 0–5 | 首测统一基础 λ=1.1；λ 的上限不是次数上限，分开配置 |
| 亲和变异 | 泊松 μ=0.25，最多 4 次；10 级蓝/紫/金/彩为 72/15/7/6% | 采用独立通道；扩成十级，各物种配置自己的亲和池 |
| 普通天气 | R:SR:SSR=140:10:0，每小时刷新 | 采用该自然抽取比例，SSR 经保底或特殊事件进入 |
| SSR 彩因子保底 | 累计 32 次后，下一次含 SSR 的结算给彩因子 | 明确第 33 次触发；补全重置、满槽和多天气规则后实现 |
| 果实品质 | mutationBonus × massRatio，门槛 0/25/50/150 | 采用综合评分结构；因子分值是项目适配，不能冒充原版 |
| 变异肥 | λ +0.23/+0.64/+1.08/+1.29，按幼苗期覆盖折算 | 采用四档，按每收获轮次一次使用机会 |
| 增重肥 | +[0,0.4]/[0.3,0.6]/[0.5,1.0]/[0.8,1.2] | 采用重量倍率加法，不继续乘 1.5/1.8/2.2 |
| 体型 | <0.6 迷你，3–5 大型，≥5 巨大化 | 保留阈值；体型由重量派生，不放入普通随机词条池 |
| 杂交 | 同槽双方有 30%、单方有 25%；重量另判 20%；普通/浓缩精油上限 3/4 | 采用起测值；补全同槽选父母、保底对象等缺失规则 |
| 杂交额度 | 父母各一次，每周 90 次；普通与重量分别 10 次保底 | 采用资格与额度骨架，保底明确第 10 次触发，独立计数 |
| 多人培育 | 最多 8 人，360 工作量/秒/人，参与者独立奖励 82/8/10% | 采用人数、速度及单人基础奖励池；多人概率提升为用户要求的项目扩展 |

附件没有提供完整因子表、全等级亲和表、天气重量表、房间天气保底次数、鉴定各格倍率。上述缺口必须保留来源标记，不能用猜测数值宣称完整复刻。

## 6. P0：生长阶段、天气、亲和与保底

- [ ] 状态改为：播种/开始生长 → 幼苗 → 预成熟结算 → 普通成熟或问号待培育 → 培育完成 → 收获。

- [ ] 天气变异：抽 N~Poisson(λ)，每次按天气时长占比选天气，再按该天气因子池抽取，最后处理槽位候选。

- [ ] 天气每小时整点刷新，全时段可用；不照搬夜间强制普通天气，以免夜间用户长期失去稀有机会。
- [ ] 房间自然权重 R=140、SR=10、SSR=0。现有六天气映射到三档，补足原版五种 SR/五种 SSR 的主题配置；先用图标承载，视觉效果分批制作。

- [ ] 项目房间 SSR 起测保底：连续 12 个非 SSR 小时，第 13 个小时 SSR；自然/特殊 SSR 出现后重置。此次数为新增提案，需根据首次彩色分布校准。

房间 SSR 保底、农场彩因子保底是两套计数，不能混用。原版 10 级亲和彩占 6% 指亲和抽取中的品质占比，不是每轮 6% 必出彩。所有界面概率说明都标清条件。

### 8.2 多人提升奖励概率

- [ ] 单人额外奖励池沿用参考：普通种子 82%、因子喷雾 8%、神秘种子 10%，每名有资格参与者独立抽一份；原参考称因子喷枪，此处接入第 13 节统一道具。
- [ ] 有效参与资格起测：累计主动参与至少 30 秒且贡献不少于总工作量 2%；邀请卡提示剩余工作是否足以取得奖励资格。
- [ ] 令 n 为本次满足贡献条件的不同玩家数，上限 8。优质奖励总概率 q=18%+9%×(n−1)/7，范围 18%–27%；喷雾和神秘种子按 8:10 分摊 q，普通种子概率为 1−q。
- [ ] 人数增加同时提升速度和优质概率；界面展示当前确定加成及条件，不能用瞬时围观人数计算最终奖励。
- [ ] 主人果实永久归主人；帮助者不分走果实、种子或繁育资格。
- [ ] 已取得资格的参与者离开后仍可领取一次奖励；奖励以任务 ID＋账号 ID 幂等结算。
- [ ] 每账号每天前 5 次合格培育发物资奖励（含自家与帮助他人，起测值）；之后仍可加速和留共同记录，开始前明确显示不再发物资。需模拟该额度对社交意愿与资源供给的影响。
- [ ] 普通/神秘种子的候选池、数量和喷雾品质必须另表配置，不能只用“稀有奖励”占位。

验收：单人路径可走通；多人确实更快且优质奖励分布更高；加入/退出/断线不丢贡献、不重复领奖；卡片已有词条不会被培育随机删掉。

## 13. P1：珍稀喷雾与每日差异货架

本节的喷雾、刷新及库存方案为用户新方向的项目设计，附件不包含可直接复刻的全套喷雾规则。喷雾是稀有消耗品，不等同于每轮肥料，也不增加第六个因子槽。

### 13.1 按类型限定范围，使用时揭晓

| 类型候选 | 使用效果 | 候选举例 | 与既有规则的关系 |
|---|---|---|---|
| 色彩喷雾 | 随机改变表现颜色 | 奶油、薄荷绿、樱粉、淡紫、海蓝 | 独立外观色，不额外加评分或售价，不作为可遗传因子 |
| 果实喷雾 | 果实槽随机因子 | 糖心、奶香、蜜心、星瓤 | 按池抽取，遵守果实槽容量 |
| 材质喷雾 | 果皮槽随机因子 | 青瓷、珠光、晶透、琥珀 | 按池抽取，遵守果皮槽容量 |
| 挂饰喷雾 | 挂饰槽随机因子 | 花结、风铃、蝶舞、流星环 | 遵守两个挂饰位及互斥组 |
| 主题喷雾 | 主题内随机因子 | 月夜池：夜染、月华、星尘 | 每个结果标明实际槽位，稀有池单独配置 |

表中为主题及候选示例，不是已冻结的完整掉落池；具体品质权重、上架率、数量和价格纳入 P0 经济模拟。不同类型、不同档次的喷雾不能共享一套不透明概率。

- [ ] 商品卡展示已知喷雾类型、档次、用途、候选结果和概率；购买获得未使用喷雾，使用时只抽一次，不在购买和使用各做一次隐藏随机。
- [ ] 首版支持对自己成熟且已揭晓的在地果实或背包收获物使用；未揭晓/培育中的果实锁定，防止邀请公开词条被改写。
- [ ] 使用前选择目标并预览候选池；确认使用时一次扣道具并保存结果，重启、取消动画、切换目标不重抽。
- [ ] 结果为空槽则可装入；槽已满或冲突时，显示新旧对比并让玩家选择替换或保留原状。保留原状仍消耗已使用喷雾，使用前说明；关闭界面保留待决结果。
- [ ] 重复命中已拥有词条不额外加分，如何降低重复感与是否设置累计定向兑换在模拟阶段评估；首版不得暗中临时改概率。
- [ ] 因子喷雾产生的词条可按正常规则进入后续杂交候选；色彩喷雾的纯外观色不遗传。
- [ ] 喷雾影响本批果实，不自动改多轮植物的基础基因、不复制到后面所有轮次；收获后保留本次效果。
- [ ] 明确纯染色与因子：喷成紫色不等于获得“异色·紫色”词条；投喂若要求该词条，纯染色不能替代。
- [ ] 若喷雾令已揭晓果实升为彩色，首版不再生成新的问号培育任务，防止反复换词条刷合作奖励；喷雾用自己的揭晓演出反馈。

### 13.2 每天逛自己的店，也有理由去朋友家

- [ ] 日货架按账号＋固定现实日期＋配置版本生成并持久化，首测北京时间 04:00 换日；重登、换角色、换房间不刷新。
- [ ] 自家与好友独立生成今日喷雾和种子货架，允许部分撞货，但不能所有玩家看到同一套商品。
- [ ] 基础种苗维持稳定获取；每日差异集中在种子组合、稀有种子和少量珍稀喷雾，避免基础种植必须依赖好友数量。
- [ ] 替换现有稀有货架每五分钟重抽的逻辑；普通补给若保留补货，明确其独立规则，不重置日喷雾库存。
- [ ] 好友列表/名片展示今日特色商品图标和可购买状态；可以看到“朋友家今天有月夜喷雾”，再主动去逛店。
- [ ] 推荐每位购买者独立限购同一货架，主人买过不导致好友全都无货；同时设置账号跨全部商店的珍稀购买总额度。具体额度由供给模型决定，避免加好友数量等于无限稀有投放。
- [ ] 确认采用系统生成商店，首版不做玩家自由定价寄售；购买消耗买家的花园币，商品进入买家背包，不自动给店主返同额金币。
- [ ] 访客购买走同一份有效报价与结算记录，处理跨日、库存变化、余额不足、并发购买和网络重试。
- [ ] “商店上架率”和“喷雾使用结果概率”分别列出；培育奖励也发喷雾时一起计算全账号每日供给，不只控制商店来源。

验收：两名玩家同日货架可不同，彼此能购买对方货架；刷新边界准确；一笔购买只扣一次钱、发一次货；喷雾结果不会因读档改变，效果遵守槽位与遗传规则。

## 15. P1：每个角色的食物心愿、投喂与成长

### 15.1 角色独立成长，果实有新的消耗用途

- [ ] 多角色分别养成共享账号果实库存；购买额度与供给不随角色数无限增加，模拟养 1/3/5 个角色时的真实成本与达到目标等级的天数。

### 15.2 头顶气泡 → 提交 → 吃到 → 升级

- [ ] 头顶显示想吃的水果图标及所需词条小标记；点击打开投喂提交面板，不在点击气泡瞬间自动扣物品。
- [ ] 面板显示角色、需求、经验奖励、当前背包匹配物；满足条件的候选优先，不足时逐项指出缺物种还是缺词条。
- [ ] 默认按低消耗价值排序，收藏锁定和未揭晓物品不进入可提交列表；已保留作亲本的稀有果实显示提示，由玩家自行选择。
- [ ] 提交前展示具体果实及完整词条，清楚说明会消耗这颗果实；只接受背包已收获物，不直接吞掉仍在地里的整株多年采摘植物。
- [ ] 正确提交时原子扣果实、标记心愿完成、增加本角色经验、发解锁记录；错误材料不扣除，重复点击或断线重试不重复消费/加经验。
- [ ] 食物图标靠近角色并消失，播放合适的现有吃东西/开心动作；缺素材时用图标、气泡与兼容表情反馈，不自动生成新视频。
- [ ] 升级展示新互动预览和入口；演出中断后可查看结果，不能因重复播放再发经验。
- [ ] 心愿气泡与聊天、思考、培育提示协调展示，支持收起，仍可从角色详情打开；不持续遮挡或闪烁催促。

### 15.3 等级解锁更多双人互动

以下为首批玩法安排候选，等级门槛和经验曲线需一并测算。已有打招呼、聊天、喝茶、送心的试演/基础能力不追溯锁回去。

| 角色等级候选 | 新增互动方向 | 实现与呈现要求 |
|---|---|---|
| Lv.1 | 保留基础交流与已有互动 | 新玩家进入房间即可与别人交流 |
| Lv.3 | 送花互动 | 独立花朵物件＋双方回应；若实际赠送果实，需另外明确资产转移 |
| Lv.5 | 并排合影 | 双角色独立排布＋背景/相框，不要求身体接触 |
| Lv.8 | 表情接力 | 一方表达、另一方选回应，多轮动作顺序清楚 |
| Lv.10 | 共同庆祝 | 双方确认后播放兼容动作与共享特效，可接培育成果 |

- [ ] 解锁绑定发起角色；推荐发起者达到等级即可邀请低等级好友参与，避免双方都要先练级才能一起玩。
- [ ] 对方玩家明确接受或按已有预授权回应；等级不代替对方同意，不自动替真人选择回应。
- [ ] 按现有表情包/预渲染视频能力制作，使用平移、物件和特效；不承诺任意角色都能真实牵手、拥抱或击掌。
- [ ] 未解锁内容显示等级与效果预览；已解锁但缺特殊素材时提供兼容呈现，不让等级奖励变成不可用按钮。
- [ ] 角色等级主奖励先集中在互动内容，不同时提高种植、商店稀有率和喷雾概率，避免成长优势多重放大。
- [ ] 每个门槛提供基础心愿路径与完成词条心愿路径的预计天数，曲线通过模拟后冻结，不能只有等级列表没有体验节奏。

验收：两个角色心愿和经验互相独立；满足物种但不满足词条无法提交；正确投喂只消耗所选果实一次；角色升级确实解锁可用互动；切角色、换日、重启和网络失败均不重复发奖。

## 16. 更新后的开发批次与整体验收

| 批次 | 开发内容 | 可体验的结果 |
|---|---|---|
| A：数值与资产基础 | 五槽、品质、天气/亲和、肥料、稳定角色 ID、完整产消模拟 | 果实来源与用途明确，后续模块共用一致的资产与身份 |
| B：单人日常循环 | 喷雾使用、自己每日商店、食物气泡/投喂/角色经验、单人培育 | 角色提出心愿，玩家找材料、改词条、投喂成长 |
| C：真实好友来往 | 服务端账号资产、统一名片、土地/商店查看、跨店购买、邀请卡、多人培育 | 玩家确实能逛好友的店和地，一起培育并领取不同奖励 |
| D：互动与长期收藏 | 角色等级互动解锁、杂交与喷雾来源完善、新词条视觉持续扩充 | 成长解锁新的相处方式，收藏带来持续合作目标 |
| E：深层玩法 | 重量鉴定、太阳花、更多主题货架与互动 | 在已验证的日常循环上拓展长期内容 |

B 可用隔离的本地数据完成体验验证；C 接入真实用户前，必须先完成账号、资产和交易权威化。不能把本地假商店、缓存角色或模拟好友演出当作真实跨用户功能交付。

- [ ] 增加日切测试：购买与投喂跨刷新时刻、设备时区变化、同账号多端打开，货架与心愿不能重抽或重复领。
- [ ] 增加联合交易测试：同一果实不能同时出售、投喂、喷雾或用于冲突操作，失败需保留一致库存。
- [ ] 增加供给报告：每周喷雾商店与培育总投放、每种目标词条成功率、跨店访问收益、投喂消耗占比、不同角色数量的升级速度。
- [ ] 增加真实玩法验收：角色想吃蜜心草莓 → 玩家从好友入口查看种子/喷雾 → 购买并种植/使用 → 获得符合要求的果实 → 选择投喂 → 升级 → 向该好友发起已解锁互动。随机步骤用固定测试结果验证完整流程，同时另测真实概率分布。
- [ ] 观察好友商店回访率、喷雾使用满意度、心愿完成/更换率、投喂后互动使用率，以及有没有为了交每日单误耗收藏的情况。

以上三模块已纳入主线，不再把好友商店或角色成长作为纯装饰附属。数值优先保证需求可理解、基础成长可达、稀有结果值得分享、互动解锁确实能用。
