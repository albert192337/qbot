# 花园生活模块：实现与验证

2026-09-22。本轮交付喷雾、每日差异商店、真实账号拜访与合作培育、角色投喂成长和互动邀请。对应 `garden-next-development-todo-2026-09-22.md` 的 B/C 批次及部分 D。客户端与 rooms 服务已构建并在隔离数据中验证，尚未部署公网服务。

## 怎么体验

重启新版客户端，在花园打开「今日小店」「喷雾」「食物心愿」。选择自己的角色后，桌宠出现可收起的食物图标；点击只打开提交面板，选择具体果实才会消费。角色心愿与植物经验独立。

真实多人入口在「朋友花园 → 开通 / 进入联机花园」，需要配套新版 rooms 服务。联机资产从服务器的新花园开始，本地收藏保留，可以切回；不上传客户端钱包或合并不可信旧资产。好友、公共房间成员、聊天昵称及培育邀请可以进入同一土地/商店页，查看不会退出当前房间。主人许可时离线也可购物。

有问号的果实展示已有词条，可邀请好友或主动发到世界频道。自己也可以完整培育；对方从邀请打开土地并参与。培育后的果实归主人，每名达标参与者独立领取额外物资。主人先收获或改为私密，不影响已获得的领取资格，可从「朋友花园」找回待领奖记录。

角色 Lv.3/5/8/10 分别开放送花、合影、表情接力、共同庆祝。右键菜单支持现有本地角色演出；真实玩家在当前房间成员旁发起邀请，对方在「朋友」接受后双方播放现有兼容动作和物件提示。合影目前是相机物件与动作演出，不会自动保存照片；接力使用预设轮次。

## 词条及资产一致性

词条表扩展为 60 个定义。56 个普通词条都能从对应喷雾池获得；旧巨大化继续原生长/遗传来源。新迷你、饱满、大型在图鉴明确标记为后续体型配置预览，不掉落。新增词条使用现有透明原画叠加材质、稀疏矢量饰件；完整 3D 专属挂饰和独立轮廓模型仍未制作。

使用喷雾时扣瓶并保存唯一候选；满槽允许替换同槽旧词条或保留原样，后者仍消耗喷雾。待决目标禁止出售、投喂和冲突操作。颜色与词条分开，纯染色不计售价、不满足词条心愿、不遗传；只影响本批果实，收获保留、后轮不复制。已揭晓果实喷成彩色不会再次生成培育奖励。背包喷雾获得的新词条也会记录发现。

投喂校验物种及全部指定词条，额外词条允许；锁定及未揭晓物品排除，只吃背包里的选中果实。角色重命名、切角色不会复制经验；每天重新生成心愿但不清经验。漏喂无惩罚。

服务端按已验证的游戏账号保存花园，拒绝客户端上传资产与测试催熟。交易编号绑定指令及角色，重复请求不再消费；客户端保存未确认交易，丢响应后重新读取会自动按原编号核对，即便原果实已被消费也能恢复。存档写入失败回滚；旧文件备份，损坏时拒绝覆盖。访问权限为仅自己/好友/公开；本轮土地与商店共用这一权限。

## 开发入口与验证

- `app/src/shared/garden-life.ts`：货架、喷雾池、角色等级与合作配置。
- `app/src/main/garden/life-rules.ts`：喷雾、投喂及日额度纯规则。
- `app/src/main/garden/network.ts`：网络交易与丢响应恢复。
- `rooms/garden.mjs`：权威存档、访问权限、共同培育、额外奖励。
- `rooms/server.mjs`：好友/世界邀请、双方接受的互动调度。
- `app/src/renderer/garden/life.ts`、`pet/food-wish.ts`：页面与桌宠心愿。

部署前运行 `npm run build:garden`；提交生成的 `rooms/generated/garden-core.cjs`，rooms 运行时不跨目录依赖 app。根 `npm run build` 已串入生成步骤。

已验证：

- `npm run check`：管线 135 项、App 840 项、生成服务 2 项通过；保留原有 1 项跳过，类型检查通过。
- `npm run build -w app`：成功；存在原有及循环依赖相关的动态/静态 import 同模块打包提示，无构建错误。
- `scripts/test-garden-network.cjs`：真实双 WebSocket 账号、访问权限、跨店购买、幂等重试、错指令、投喂、互动等级/接受权限、服务重启。
