2026-09-22。用户提供已付费导出的 `pineapple 3d model.glb`，要求由 agent 减面，并查看替换原 3D 草莓试种位置的效果。

## 资源

原文件保留在用户 Downloads，未改写。项目只包含轻量副本 `app/src/renderer/garden/assets/models/pineapple.glb`。

使用 meshoptimizer 1.2.0 的 `simplifyWithAttributes`，32,000 三角面目标，法线权重 0.3、UV 权重 1，误差上限 0.01；返回归一化近似误差 0.00088025，此数值不是视觉无损保证。随后 compact 顶点。贴图以 Pillow 11.3.0 缩到 2K；普通、粗糙度/金属度、法线均内嵌在 GLB。优化工具仅用于离线制作，不增加客户端运行依赖。

叶果依据高度与原色贴图分类，离线写入命名材质 `pineapple-fruit` / `pineapple-crown`；不是人工重拓扑，局部边界仍可继续美术精修。实际四角度减面前后对照已查看，图在 `output/pineapple-garden/optimization-comparison.png`。本机制作脚本和详细参数保存在忽略目录 `work/pineapple-review/`。

## 接入范围

- `pineapple-3d.js` 只加载一次模型，多个实例共享几何和贴图；每株独立材质。复用现有 `strawberry-3d.js` 的唯一 WebGL renderer、透明 Canvas 合成、20fps 上限、可见性/减少动态效果/移除节点释放逻辑。
- 3D 模式允许草莓和菠萝播种，前端和本地 service 共用 `supportsGarden3D`。菠萝成熟阶段与收获物、种子徽标使用 GLB；成长/再生未成熟阶段继续原手绘资源，不把成熟模型冒充完整生长动画。
- 普通、闪亮、晶透/冰冻/凝露、玉润、虹彩等使用果实材质或独立星点；叶冠保留原色。巨大化沿用显示尺寸，双生复制共享网格。其他高级附件并非完整美术实现，不宣称全部词条已经适配。
- 与原先一样，透明材质折射的是 Three.js 场景与环境，不是真实桌面壁纸。
- 模型载入失败保留原画；过期的异步加载不会给已移除节点装载。未揭晓资产继续通过原 `needsReveal` 遮蔽，不先暴露模型。

## 预览与验证

构建 App 后，用 Electron 执行 `scripts/preview-pineapple-garden.cjs --show`。脚本使用内存状态和临时 userData，禁止联网；不读取或修改真实花园存档。

桌面六地块依次为旧草莓对照、普通菠萝、闪亮菠萝、晶透＋闪亮、玉润＋闪亮、虹彩＋闪亮。详情窗口可点不同土地查看、收获、在空地播种。关闭详情窗同时关闭透明地块窗；地块窗 Esc 可隐藏。

已验证五种新模型、旧草莓保留、浅深透明背景、2D/3D 切换不改数据、收获/再生/背包、菠萝播种及 GLB 缺失回退。证据见 `output/pineapple-garden/result.json` 与截图。原 `scripts/test-garden-3d.cjs` 回归通过；本地 service 额外覆盖菠萝单次/批量播种。构建及类型检查通过。没有把短时试摆当作长期功耗测量。
