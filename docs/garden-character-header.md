# 花园角色区与等级土地

2026-09-25，按本轮用户确认实现。地块采用角色等级：1 级 3 块，2/3/4/5 级分别 4/5/6/7 块，之后保持 7 块。

## 界面

- 花园原绿色宣传页头改为当前角色形象、名字、等级、级内经验条、今日三份心愿和余额。查看背包时页头保持可见，作为投喂目标。
- `⇄` 打开角色选择，显示每个角色在当前本地/联机花园中的等级和累计经验；选择后激活对应桌面角色。未培养角色从 1 级显示，不复制其他角色的成长。
- `↗` 打开二级成长详情，列出土地解锁和原有送花、合影、接力、庆祝奖励。长时升级天数估算不再占主界面。
- 移除“食物心愿”标签页；旧 `feeding` 深链转到背包与角色区。每日免费更换心愿仍保留在各条心愿的小按钮。
- 可投喂果实从收获篮拖到页头，或使用果实卡上的投喂按钮。收藏、待揭晓、鉴定中的果实不参与投喂；同一果实匹配多份心愿时优先经验较高的心愿。操作失败保留果实，成功后更新心愿、经验和土地数。
- 拖动携带开始时的角色标识，后端再次核对；角色切换或刷新中的过期结果不能把果实喂给另一角色。

## 土地与存档

土地与库存仍由账号共享，角色成长独立；当前角色等级决定可重新播种的土地。切回低等级角色不删除已有作物，超出当前解锁数量的旧植物仍展示并可照料、完成全部采摘；腾空后需达到相应等级才能重新播种。

存档保留七个固定槽位，未解锁的空地不显示、不计入批量播种。原六地块存档校验后只追加一个空槽与一级土壤，不移动旧地块索引、不修改植物结果。土地升级与播种均由规则层校验，客户端隐藏按钮不是唯一限制。

本地、试演与 rooms 服务共用规则；第七地块已接入合作请求、访问链接和土壤升级。桌宠田间动作使用与展示相同的七槽位置，避免升级后站错地块。朋友土地按主人的解锁数量及已有植物展示。

- 花园规则、存档服务、天气、合作、桌面培育等 116 项单测通过（全套运行后补齐旧窗口替身并复验相关用例；分布模拟需放宽测试时限）。
- 独立服务测试：`scripts/test-garden-progression-server.cjs`、`test-garden-coop.cjs`、`test-garden-v3-server.cjs`。
- 隔离真实 renderer：`scripts/test-garden-character-header.cjs`，覆盖角色切换、奖励二级页、拖放事件、失败重试与重复投喂、560 像素布局、滚动后投喂区可见、旧深链和桌面土地数量。截图与结果在 `.superpowers/garden-character-header/`。
- 拖放回归向实际 renderer 发送 DragEvent，不等同 Windows 跨窗口原生拖放验收；当前投喂目标为花园页头角色区。
- 只改本地代码并生成独立服务规则，不改用户真实存档，不自动重启当前桌宠，不部署公网。新版联机规则需要随 rooms 服务更新；本轮不宣称在线旧服务支持第七块地。
