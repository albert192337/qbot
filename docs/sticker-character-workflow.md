# 表情包新角色工作坊

入口：新朋友孵化表单 / 角色库 →「从表情包创建」。已有表情角色进入同一工作坊编辑。

## 本地流程

1. 选择单角色文件夹（只读这一层 GIF，不混入其他子目录），选择主形象、命名。
2. 整库浏览：18 张一页、搜索、开放多标签、按页追加标签和开启/关闭自由表达。不设 50 张限制，不要求三视图。
3. 场景独立选择待机、拖拽、睡觉、放松、开心、不高兴、打招呼、花园播种/收获。卡片可一键选为某场景。
4. 本地创建：原 GIF 保存在 imported/_raw，VP9 alpha 动作在 actions，逐张原子保存 manifest。不会激活或上传；单张失败保留其余成功结果。
5. 原片、选帧重做、按主形象全新生成分别选择。后两者经显式外发/费用确认，使用现有本地 Ark 图片→视频生成链路，不覆盖原件。新版本默认不加入自由表达；完成后预览并手动采用。
6. AI 整库分析是显式操作：每批 12 张，首中尾帧，开放多标签、循环适合度、多角色提醒。失败项不覆盖现有标签。人工采用、保存后才生效；关键帧判断不代表真正无缝循环。
7. 上传前检查包大小、确认公开分享授权，沿用装扮市场入口。50 MB 限制。不会自动公开素材。

## 数据与兼容

- `manifest.stickerLibrary` 保存素材 ID、原件相对路径、语义标签、启用状态、场景映射、待采用的新版本。
- 所有原片是唯一 customAction，场景是引用同一 webm 的别名；多表情同语义、多标签同表情均可。聊天和自动脑共享 brainActions，全部启用条目进入动作白名单，不只几个固定槽。
- 本轮保持全量动作描述提供给模型；超大库的向量检索、硬冷却/权重调度尚未加入。
- 上传收集标准/导入/预设/自定义动作，路径去重。旧 imported/*.webm 在包内重映射到 actions/；不扩展任意路径权限。
- 分享包不含原 GIF、人设或完整生成提示词；保留开放表达标签和版本动作说明，表情角色带 source.png。原件仅本地保留，下载者无法使用未分享的原 GIF 取帧。
- 原图透明通道保持，不按白色抠像，不改变白狗身体。新角色转码使用 384 方形画布和快速 VP9 设置；原件未缩减。既有 gifToWebm 默认设置不变。
- 新版本动作生成目前使用自备 API Key 的本地管线；不承诺云邀请码能直接调用此入口。真实生成及无缝循环效果须单独验收。
- 中断创建保留已落盘部分；尚不支持跨重启自动续导未转码的源文件。失败项重新导入会新建角色，不覆盖旧角色。
