# 桌面立体花园

2026-09-29。保留现有 2D 花园，通过原来的画面切换与桌面工具栏的「3D / 2D」切换进入成片立体田区。

后续视觉修订：降低镜头并加入柔和透视，调整土地和草边。独立构建、正式花园构建与 Electron 11 类验收通过（含 24 格、640×480、旋转点击）。正式花园页面已刷新，刷新时窗口收起，因此保留隐藏状态；种植数据不变，未重启。最新 `live-switch.json` 记录本次隐藏刷新，实际截图见 `twenty-four-plots.png` 与 `small-screen.png`。

## 已实现

- 3D 工具栏下方提供地块数量输入、−1／＋1、换一组和恢复。最多预览 32 块，每四块成田；超过四块自动扩展到下一片。最小数量为当前真实可见土地数，预览数量只在页面会话中保留。
- 新增预览地块随机使用草莓／菠萝，以及异色加巨大化／双生／闪亮的组合；加减数量保持已有样本，换一组重新随机。草莓按贴图颜色遮罩变色，保留叶片和种子；双生和体型共用原模型。悬停显示词条，预览地块不进入存档、采摘、作物计时或桌宠照料位置。

- 一个透明 Three.js 场景承载整片草地、田格、走道和植物，透视相机以 47° 俯视、34° 视场展示更多果子正面，并保留轻微近大远小。每四个种植位组成一片田，最多三片横向排列，其余向后扩展。
- 土地使用略带起伏的圆角轮廓、柔和深色边缘和土粒；草地边缘以疏密不同的小草与少量小花装饰。镜头随田区尺寸和旋转重新计算取景，动态地形在重建与关闭时释放。
- 实际加载已有 `pineapple.glb`、`strawberry-tripo.glb`、`strawberry-base.glb`。草莓与菠萝共享镜头和光照；幼苗用简化叶片表示。没有生成或购买其他物种模型。
- 其他已有植物使用原手绘外观；未揭晓植物保持原保密外观。模型缺失时回退原画。草莓与菠萝仍是 3D 模式可播种物种。
- 左右旋转、视角回正、缩放、整体拖动、收起，以及原有地块菜单、播种、施肥、收获等操作。原有管理页继续显示详情。
- 旋转后的鼠标点击使用场景射线判断实际地块；投影按钮保留键盘访问与菜单定位。桌宠照料接收经主进程校验的地块屏幕坐标，切回 2D 清理投影位置。
- 共用模型几何与贴图；场景静止时不持续绘制，隐藏时暂停，恢复可见时重绘。切回 2D / 关闭页面时释放场景资源；过期模型加载不写回新场景。

## 范围与限制

- 这次不改变土地解锁、经济、存档或服务端资产。布局根据当前可见土地生成；24 格是独立内存测试场景，并非赠送 24 块正式土地。同工作区 2026-09-29 的 v0.4 经济调整目前使用四块地，本次遵循其现有状态。
- 统一场景是首版程序化地形，不是效果图的逐像素复刻。角色继续使用现有桌宠窗口，照料时走现有动作链路，不生成 3D 角色。
- 田区中先提供基础体型和部分菠萝颜色变化，复杂词条材质／挂饰的全量适配仍属于后续美术工作；详情和现有独立工坊保留原有展示。
- 镜头旋转、缩放暂在本次页面会话内保留；不向游戏存档写入新的资产字段。
