# 本地双人互动试演

2026-09-16。桌宠右键 → 双人互动（本地试演）→ 送小心心 / 请喝茶 / 一起聊天 / 打招呼 → 选择另一个已下载角色。

## 当前体验

- 复用旧串门的双播放器和窗口拓宽机制，不激活或修改被邀请角色。只读角色素材，没有付费生成、AI 请求、资产转移或真实玩家通知。
- 送小心心：心形特效从发起者飘向接收者，然后双方播放开心回应。请喝茶：邀请、双杯茶盘、双方喝茶或兼容动作。一起聊天：轮流表达/倾听，最后共同开心。打招呼：一方招呼后另一方也播放回应。
- 动作从两只角色各自的已完成标准、导入、预设、自定义动作中选择；结合表情包名称和标签，排除停用/错误条目。缺少语义匹配时回退兼容动作或待机，绝不自动生成新素材。顶部文字是固定试演台词，不是 AI 对话或真人回应。
- 台词分别锚定发言角色上方，换边后气泡与心形方向一起跟随；双人画布中心间距从 54% 缩到 34%，利用素材留白让角色靠近。两角色按实际动作的 facing 朝向面对面；没有朝向信息不盲目翻转。下方可点击“我转向”“对方转向”“换边”“结束”，校正按本次会话与具体动作记忆，换角色/新会话不写回原素材。镜像仅作用于角色画面，不翻转界面文字；素材自带文字也会镜像，用户可再次转向恢复。
- 每段至少停留 4.5 秒，短表情在完整片段边界重复播放；达到时长后，先完成的一方转为循环倾听/待机，等待另一方完整结束再共同进入下一段，不停在末帧。媒体异常设有时限，播放器保留原图/兼容动作回退。动作解析与实际解码失败回退不等同；损坏素材回退后的朝向可能需手动校正。
- 临时画布在当前显示器内避让边缘，小屏等比缩小；正常结束先淡出与轻雾遮罩，在不可见阶段恢复原位置和单人尺寸，等待主进程尺寸确认后以柔光淡入。移除重复待机播放，有工作/会议/音乐状态时直接恢复对应动作。拖拽、切角色等中断仍立即清理，避免抢回新操作。结束恢复最新工作/会议/音乐状态。拖动主角、切换角色、花园表演、隐藏、Esc 或结束按钮会取消；取消也使尚未完成的角色查询失效。页面重载重置双人窗口尺寸。

## 结构

- `shared/pair-interaction.ts`：互动类型、分段意图、动作白名单/标签匹配、朝向判断；可供后续房间互动复用。
- `renderer/pet/pair-interaction.ts` / `.css`：本地编排、双人效果、校正工具和完成/取消生命周期。
- `renderer/pet/local-main.ts`：与现有状态机、两个 Player 和拖拽/角色加载衔接。
- `main/ipc.ts`：原生右键子菜单；`main/pet-geometry.ts` / `windows.ts`：双人画布边缘适配、尺寸与位置恢复。
- 旧 `visit.ts` 保留作历史编排实现，但本地手动入口走新 PairInteraction，没有恢复自动串门。

## 范围

当前只验证本地已下载角色。真实房友的邀请/接受、双方同步、房间中的双人站位及已有网络打招呼通道仍待接入；本次新增本地打招呼已包含双方动作。没有修改或部署房间服务，也不把本地模拟回应当成远端玩家已接受。

形象主体大小受原素材透明留白影响；当前统一画布分列，不做逐帧骨骼、手脚接触或自动 alpha 轮廓对齐。任意风格/体型素材仍需实机观察。
