# 双人互动的人设台词

八种互动（送心、喝茶、聊天、招呼、送花、合影、表情接力、庆祝）沿用原动作编排，在播放前逐句调用现有文本 LLM。每句只使用发言者的人设、互动类型、当轮动作及本场已有台词，让接收者能承接发起者，而不是各自说一句无关的话。

- 本地试演读取两位角色最新的 manifest.name / persona。不修改或生成动画素材。
- 联机真人由各自客户端生成自己的台词。房间服务只同步生成结果，不接收真人的人设或 API Key；六位陪伴角色使用 `rooms/companions.mjs` 中的专属公开人设，由同场真人的客户端代为生成。
- 使用设置中的 `arkApiKey` 和现有文本模型。互动属于显式邀请/接受后的行为，与自动脑 `freeMode` 开关独立。未配 Key、旧客户端、超时或非法输出回退该轮互动的备用台词，不声称备用台词来自 LLM。
- 先生成完整的两到三轮对话，再把同一份台词发给双方。气泡随实际发言角色与动画轮次切换；接收端反转角色位置，不反转发言身份。
- 每句请求有 8 秒总截止，服务端等候最多 9 秒，不重试。重复请求、他人代答、离房、换角色、素材切换和迟到结果都有校验；本机人设修改后不发送旧结果。模型失败不阻塞互动。
- 对话不写入房间聊天记录或角色包。对方会看到角色说出口的句子；提示词要求不复述私人设定。

更新需要同时发布客户端，以及 rooms 的 `server.mjs`、`companions.mjs`、新增的 `pair-dialogue.mjs`。只更新客户端、继续连接旧服务器时，联机仍使用原固定台词。2026-09-26 晚已部署线上并正常退出、重启用户客户端，详情见 `docs/rooms-deploy.md` 最新记录。

验证入口：`app/test/pair-dialogue*.test.ts`、`garden-network-interaction.test.ts`、`pair-interaction.test.ts`、`pair-playback.test.ts`；`node --test --test-isolation=none rooms/pair-dialogue.test.mjs rooms/companions.test.mjs`；`node scripts/test-pair-dialogue-server.mjs`；隔离 Electron `scripts/test-pair-interaction.cjs`。模型调用均为模拟，真实模型语气质量不由这些测试替代。

2026-09-26 验证：19 项客户端测试、11 项服务端测试、类型检查和 App 构建通过。真实回环 WebSocket 验证接受邀请、双方分别回答、冒名拒绝、同份台词同步及离房重进后取消后续片段；隔离 Electron 验证八种互动双方身份、生成台词头顶归属、两角色视频播放、本地试演、换边和结束/打断。旧播放单测补上等待已有异步窗口交接的微任务，未修改播放器时序。截图 `.superpowers/pair-preview/tea.png`。

## 天气人设反应与实际部署验收

- 极光/流星原先直接发送固定文案，绕过自动脑开关。现在在本机读取当前角色最新人设后生成一句反应，寡言角色不强制惊呼、卖萌或写诗；天气恢复、隐藏、换角色、人设更改时丢弃旧结果。无 Key 或请求失败只保留动作，不发送旧固定句。
- 天气等待复用思考气泡；`weather:*`、`pair:*` 请求进入工具抽屉的 LLM 日志，标明生成成功、失败、未配置 Key 或备用文案。日志不含认证头。
- 天气/互动相关 27 项回归、类型检查、App 构建通过。已用用户明确批准的 3 次真实文本调用验证：当前张起灵的极光反应为「极光，在动。」；与「翻到第七页」的两轮喝茶台词全部来自 LLM，公网服务同步结果与模型结果一致。
- 真实调用通过 `scripts/verify-persona-dialogue-live.cjs`，需单独获准后设置 `QBOT_ALLOW_PAID_PERSONA_TEST=1`。使用本机当前人设和 Key（只在内存）、独立验收联机账号，结束退出房间；结果 `.superpowers/persona-live/result.json` 不含凭据。客户端运行入口、已加载人设与新进程已另行核验，不把单独写作验收声称为天气画面端到端验收。

## 用户与角色身份（2026-09-26 更新）

市场和联机现在保留角色 name/persona；用户 ID 只用于归属与鉴权，用户网名不作为角色名。虚拟用户 userPersona 用于聊天室发言，角色 persona 用于双人互动。旧包缺失的人设不虚构补齐。聊天室通过用户、虚拟用户、角色自主三类角标区分身份；角色台词保留所属用户与独立角色名快照。API Key 仅留客户端，虚拟用户发言由同场支持该能力的客户端代生成，8秒超时、不重试，失败保持安静。
