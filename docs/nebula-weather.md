# 星云梦境天气

新增桌宠右键／托盘「切换天气（测试）→ 星云梦境」。蓝紫天空、粉色云缘、稀疏星点和两组虚构星座。云层在约 1% 画幅内缓慢漂移，星光轻微明暗变化。保持 2.4 秒淡入和 3 分钟自动恢复，可随时恢复原壁纸。

这是本地观赏天气，未新增花园天气概率或变异奖励，也不接入自然天气抽取。预览期间定时天气不会覆盖手动选择。HUD 和气象台显示星云观赏状态。

## 实现

- `renderer/weather/nebula.ts` 用确定性多层噪声生成云纹，缓存天空／云雾／星点三层。没有外部素材、联网或付费生成。
- 预览画布最高 20 FPS；隐藏暂停，减少动态效果时静止。
- 正式桌面沿用原生 GDI 窗口，在图标下方合成三张纹理，约 15 FPS 持续绘制，不创建置顶前景。Windows 关闭客户区动画时改为静止。
- 锁屏、休眠、显示器变化、切换、恢复与退出沿用天气生命周期清理；原生纹理和绘图资源随窗口释放。不写系统壁纸设置。
- `VisualWeatherKind` 包含 nebula；原 `WeatherKind` 仍只定义可触发花园测试的流星和极光。

## 验证与预览

构建后使用仓库 Electron 运行 `scripts/test-nebula-weather.cjs`，添加 `--preview` 会在验收完成后留下可关闭的独立动态窗口。隔离运行档案在 `output/nebula-weather/profile`，不加载账户与正式角色存档。

截图和结果在 `output/nebula-weather`。脚本验证画布持续运动、减少动态效果静止、原生小窗实际屏幕合成随时间变化、无置顶前景、切换与恢复。原生小窗通过不等于所有 Windows 桌面布局或多显示器已验收；长时 4K 性能尚未测试。

最终验证：29 项天气相关回归、App 类型检查、完整构建通过；原生小窗与画布验收通过。新增动画后，原生源码改写入本地脚本文件启动，避免 Windows 编码命令行长度上限。正式客户端未重启。
