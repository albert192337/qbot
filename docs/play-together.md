# 一起玩与本地试演

2026-09-20。本轮实现与已确认的 [设计规格](superpowers/specs/2026-09-20-play-together-design.md) 对应。

## 直接测试

桌宠右键或托盘 → **一起玩** → **本地试演** → 开始本地试演 → 选择角色邀请。

- 可用角色：自己的其他角色、已下载到角色库的装扮角色、仍有完整可播放素材的房友缓存。没有素材的离线玩家不会伪造替身或自动下载。
- 房友缓存从本版起记录最近素材对应的成员来源。旧缓存没有来源时显示“来源未记录”；这不是 Steam 身份证明。
- 访客在桌面或房间场景中显示名字与“测试”标记。可模拟打招呼、喝茶、送心、聊天；双方使用各自已有动作，缺少专用素材时使用现有可播动作。本入口为动作与回应测试，不是新增真实双人同意协议。
- 可手填模拟回复、让单个角色离场、改变试演容量/聊天设置。小窗可移动、缩放、置顶、关闭后重开；关闭窗口不退房。
- 本地试演不会发送网络邀请、上传素材、进入公共列表，或写真实互动/经济记录。退出试演丢弃成员与聊天；本地试演没有可分享的房间码。
- 当前在真实房间时，需要先主动退出才能开始本地试演。当前角色不列为自己的测试访客。

## 用新版房间服务测试真实联机逻辑

先退出旧的 QBot 开发进程，在当前工作树运行：

```powershell
npm run build -w pipeline
npm run dev:social
```

此命令启动仅监听本机的新房间服务，然后启动应用；保留现有角色库，房间服务数据使用临时目录。结束启动器后清理测试服务。应用自身的角色、偏好和正常存档仍使用原配置；如需完全隔离应用数据，可在启动前指定 `QBOT_USER_DATA`。

要多开客户端，可在另一终端指定独立 `QBOT_USER_DATA`，将 `QBOT_ROOMS_URL` 设置为启动器打印的同一地址后运行 `npm run dev`。单实例锁按应用数据目录区分。不要复制同一个开发成员编号给两个身份。

## 本轮行为

- 独立“一起玩”主窗：首页邀请入口、公开房间设置、联机姿态与 Steam 状态；世界广场将列表、筛选和世界聊天放在一起。
- 创建房间或编辑自己当前房间。介绍 200 字、房名 24 字、人数 2–12、公开/房间码访问、语言与聊天开关；编辑不会改变房号。“使用上次设置”仅使用上次成功保存的信息。
- 公共列表按类型、语言、聊天、空位、收藏和房名筛选，按活跃、人数或最近活动排序。房间码支持八位字母与数字。
- 房间聊天为独立小窗；复制操作从主进程当前房间取值，离房后不能复制旧码。世界与房内历史各保留 50 条，正文按文本显示，支持撤回和举报；世界举报单独持久保存，暂无自动审核。
- 名字独立于举牌；本地角色和远端角色都有称号结构，未装备称号不显示虚构称号。姿态从实际可播放动作选择，心跳不反复重启动作。
- 房间连接只初始化一次；请求使用 ID 匹配。创建不盲目重试，断线不排队重发旧消息。满员验证发生在退出旧房之前。首次真实入房沿用聊天/形象/牌面同步说明。

## Steam 与部署边界

正式平台仍确定为 Steam；当前代码明确显示“Steam 尚未连接”，没有假好友或假邀请成功。真实 SDK 初始化、经过服务端验证的 Steam 身份、好友枚举、邀请与加入回调，待 AppID/许可配置后接入与实机验收。接口调查见 [Steam 调研](social-steam-research-2026-09-20.md)。

本轮实现复用现有 rooms 开发联机链路，并没有用客户端自报 memberId 代替正式 Steam 认证。房间码访问表示持有码者可加入，不是经过 Steam 关系鉴权的“仅好友”。

世界聊天、消息发送确认和扩展房间设置需要配套的新版 `rooms/server.mjs`。通过 hello 的 `social: 1` 协商；未更新的服务可以继续基础房间发现/加入，但新界面明确关闭不能确认发送的小窗聊天，设置也不假报成功。本轮未更新线上服务、未发布安装包。

房间设置预览使用当前已有的基础场景美术，不新增家园槽位；没有加入截图中的 YouTube 同听、联系方式过滤或无效的敏感词开关。

## 验证

- `npm run check`：管线、应用与生成服务回归及类型检查；已有一项跳过测试保持跳过。
- `npm run build -w app`：生产构建。
- `node scripts/test-social-server.cjs`：隔离真实服务 + 三个客户端验证权限、满员、元信息、频道、撤回、举报与退订。
- `node scripts/test-social-ui.cjs`：需要 Playwright，可通过 `PLAYWRIGHT_MODULE` 指定已有安装。使用真实 Electron、生产社交/房间代码、真实本机服务与临时角色库，覆盖真实鼠标点击、小窗重开、置顶、输入法、保留草稿、复制房号、试演入场/离场、名字、并发请求和窄窗。
- `app/test/social-client.test.ts`：单连接握手、超时不重复创建、断线不重发、取消半开连接、试演隔离、世界历史与旧服务能力识别。

原生截图保存在 `.superpowers/social-preview/`。本机验证不代替跨网络长时间联机或真实 Steam 验收。
