## 可重放流程

本地预览服务需在 24361 端口运行。配置 PLAYWRIGHT_MODULE 后运行 `node scripts/replay-sakura-trial.cjs`：既有原图→九件透明素材分离→打包→躯干/隐藏颈部校准→肩肘腕、髋膝踝定位装配→几何单测→七动作各八帧→178 动作数值检查→动态表情检查。每次输出到新时间目录，不继承旧视觉批准，也不调用付费生图。

几何检查覆盖反向弯折、角度偏差、长度异常、锚点偏离、极端折叠、无效坐标及前臂/小腿核心网格面积塌缩。面积检查使用网格中心带，尚不是 alpha 轮廓测量。当前只审阅了小樱定位 profile；不是任意角色自动识别关节。骨架与网格一致也不保证骨架姿态符合人体观感，必须保留图片复核。

自动部分是提取、装配和检查。素材选择、关节定位 profile、目标图与动态截图复核仍由助手完成，没有独立 GPT 视觉审阅 API 或后台全自动重绘决策。本次未改正式创建入口，不能宣称已经实现上传即全自动成功。
