# 立体奶油小屋：3D 场景 × 2D 角色

2026-09-11，本地视觉可行性样板。上一版 2.5D 保留，两个页面可互相切换。未接经济、多人、库存，不写真实角色或家具数据；本版临时旋转不保存。

## 已实现

- 独立 cozy3d 入口，Three.js 0.180.0 本地打包，不运行时加载 CDN。房壳、地板、圆角沙发/坐垫、桌/杯/书、蘑菇灯、书柜、盆栽均为实际几何体。
- 正交相机，有限角度比较、缩放；家具可转 45 度。柔和哑光色板、实时定向阴影和夜间点光源。
- 复用 Player 读取现有透明视频，将当前帧传给世界空间竖直角色面片。只绕竖轴面向相机，避免脚底随俯视角抬离地面。透明像素裁切，保留深度测试/写入，实现沙发前后遮挡。
- 独立接地渐变影、夜间轻微角色调色；不将角色当成真正 3D 体积照明，也不捏造背面。
- 现有角色下拉只预览，不调用 activate。隐藏页面暂停视频和绘制，恢复继续；渲染上限 30fps，像素倍率上限 2。
- 空地点击直线移动，遇家具停下。这里只验证空间关系，未做绕路寻路、走路动作切换、家具拖动或坐卧交互。

## 明确限制

这不是动森质量的成品美术：目前是原创程序化模型、纯色材质。仍需材质微细节、柔影调校、美术精修。粗线条贴纸比柔和角色更容易显得分离；原素材自带椅子/道具不会自动删除。角色画布的透明留白尚未按每个动画单独校准脚底。相机不支持自由环绕。

所有布置是演示，不新增家具奖励，不进行付费生成。没有多人互动实现；长期性能和低配置显卡未验收。3D 主入口为 JavaScript，因此 App TypeScript 检查不覆盖该文件；用实际构建与 Electron 运行验证补充。

## 验证

构建 App 后运行 `scripts/test-cozy3d-room.cjs`，用 `PLAYWRIGHT_MODULE` 指向本机 Playwright；`QBOT_COZY_REAL_CHARACTERS` 可指向用户角色目录，只读。fixture 使用独立临时 userData，阻断 HTTP(S)。截图在 `.superpowers/cozy3d-preview/`。覆盖加载、实际动画、前后/夜景/旋转截图、小窗口以及正式数据零写入；截图需人工检查，不等同像素级遮挡自动断言。

交互预览：以 `QBOT_COZY_3D=1`、`QBOT_COZY_SHOW=1` 运行 `app/test/fixtures/cozy-main.cjs`。正式开发入口从「试住奶油小屋」顶部切到 3D。
